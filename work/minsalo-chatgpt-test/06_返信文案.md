```
ご連絡ありがとうございます。テスト発注の件、条件承知いたしました。
お引き受けさせていただきます。

納品は8/25を予定しております。

着手にあたり、3点ご確認をお願いいたします。

1. ご共有いただいたドライブフォルダですが、当方から閲覧できない状態でした。
   お手数ですが tatsumi611216@gmail.com へ編集権限の共有をお願いいたします。

2. 台本のフォーマット指定（想定尺・話者形式・既存のテンプレート等）が
   ございましたら、ご共有いただけますと助かります。

3. 操作録画について、尺や形式のご指定はございますでしょうか。
   特になければ、要点を3〜5分に編集したものをご提出いたします。

よろしくお願いいたします。
```

### 意図

- **質問は3つまで。** 多いと「自分で判断できない人」と見られる
- 参考動画のトンマナは**自分で分析する前提**で書いている（聞かない）
- 納品日を先に宣言して、期限より前に出すことを既成事実にする
- ドライブの件を1番目に置く。これは先方のミスなので、指摘というより事務連絡の体で

### 送ってはいけない質問

| NG | 理由 |
|---|---|
| 「どのような構成にすればよいですか」 | 構成を作れない人と判断される |
| 「参考動画のトンマナを教えてください」 | 見ていないことがバレる |
| 「継続の場合の単価は」 | 今聞くと印象が悪い。テスト評価後に |
| 「Claude Codeはどこまで使っていいですか」 | 使えることが前提の募集 |

## B. 追加で確認したくなった場合（1回にまとめる）

質問は**小出しにしない**。まとめて1回で送る。

```
制作を進める中で、2点確認させてください。

1. 本台本は、ご提示いただいた3チャンネルのうち、
   どちらの方向性に寄せるのが適切でしょうか。
   拝見したところ、業務効率化寄りのものと副業収益寄りのもので
   訴求が分かれているように見受けられました。
   ご指定がなければ、3つの共通項である
   「初心者向け・業務効率・実演ベース」で進めます。

2. 台本内で紹介するツール操作は、実際の画面を想定して
   手順まで書き込む形でよろしいでしょうか。

お手数をおかけしますが、よろしくお願いいたします。
```

> **「ご指定がなければ〜で進めます」を必ず添える。**
> 返信がなくても止まらない人だと分かる。これは継続発注の判断で効く。

## D. 単価について（テスト評価が返ってきてから）

**テスト提出前・提出直後には絶対に触れない。**
「継続でお願いしたい」と言われた段階で、初めて以下を出す。

```
ありがとうございます。ぜひ継続でお願いしたく存じます。

進め方について、2点ご相談させてください。

1. 月あたりの想定本数をお教えいただけますでしょうか。
   本数が読めますと、リサーチの型を作り込んで
   納期を短縮できるかと考えております。

2. 継続時の単価についてもご相談させていただければと存じます。
   今回の制作では、リサーチと裏取りに◯時間、
   執筆に◯時間、録画と編集に◯時間を要しております。

ご検討いただけますと幸いです。
```

**実作業時間を先に出す。** 金額から入らない。
「安い」ではなく「この工程にこれだけかかる」と事実を置くほうが通りやすい。
