### 13:40 ｜ プロンプト1：長い資料を読まずに済ませる

1つ目は、長い資料を読まずに済ませるやつです。

30ページのPDFが送られてきて会議まであと20分、みたいな場面ってありますよね、あれ普通に読むと私の場合は40分くらい溶けます。

で、多くの人は「要約して」と打つと思うんですけど、実はこれ、いちばんもったいない打ち方なんです。

要約してとだけ言うと、資料の中で目立つ部分だけが拾われて判断に必要な部分が落ちるんですよね。

だから、こう打ってください。

```
以下の資料を読んで、次の3点だけ教えてください。

1. この資料が主張していること（1文で）
2. その根拠として挙げられている数字（箇条書き）
3. 書かれていないが、判断するために本来必要な情報

資料：
"""
（ここに貼る、またはファイルを添付）
"""
```

ポイントは3番で、書かれていないことを聞くという発想ですね。

実際に画面をお見せしますね。

いま、20ページの提案書を読ませました【収録時実測】。

主張が1文、根拠の数字が4つ、足りない情報が3つ出てきましたね【収録時実測】。

この3つ目に「導入後の運用担当者が誰なのか書かれていません」と出てます。

会議で最初に聞くべきことが、読む前に分かるわけですね。

たとえば、他社から届いた提案書を読むときって、良さそうに見える部分に目が引っぱられますよね。

でも実際に判断で効くのは、そこに書いてない運用の手間とか解約するときの条件だったりするんですよ。

たったこれだけで、資料を読む時間が私の場合は半分以下になりました。

注意点もあります。

出てきた数字は、必ず元の資料に戻って自分の目で確かめてください、拾い間違いは起きますからね。

ここを飛ばすと、間違った数字のまま会議で喋ることになりますからね。

### 16:20 ｜ プロンプト2：気の重いメールを一発で書く

2つ目は、気の重いメールを書くやつです。

納期を延ばしてもらうお願いとか、こちらのミスを謝るメールってありますよね。

```
以下の要件で、取引先へのメール本文を書いてください。

・相手：初めてやりとりする会社の担当者
・目的：納期を3日延ばしてもらう
・こちらの非：あり（社内確認が遅れた）
・希望するトーン：低姿勢だが、言い訳がましくない
・長さ：200字以内

言い訳に読める表現は使わないでください。
```

たとえば、こちらの社内確認が遅れて納期を延ばしてもらう場面って、いちばん書き出しが重いですよね。

こういうときこそ条件を6行だけ並べてから頼むと、悩んでた10分が1分で片づくんですよ。

いちばん効くのは最後の1行で、やってほしいことだけじゃなく、やってほしくないことを最後に置くんですよ。

実際に画面をお見せしますね。

最後の1行を消した版と、付けた版を並べてみます。

消した版は、社内の事情を説明する文が3行入ってきました【収録時実測】。

付けた版は、その3行が丸ごと消えて、お願いと代案だけになってますね【収録時実測】。

たったこれだけで、そのまま送れる文面に近づくんですよ。

ちょっと注意があります。

出てきた文をそのまま送るのはおすすめしないので、固有名詞と日付だけは必ず自分の目で見てから送ってください。

送信は取り消せない作業なので、ここだけは手を抜かないでほしいです。

### 19:00 ｜ プロンプト3：自分の考えの穴を見つける

3つ目は、自分の考えを整理するやつですね。

皆さん、ChatGPTに相談すると「素晴らしい着眼点ですね」みたいに、だいたい褒められませんか。

あれ、気持ちはいいんですけど、判断の材料にはならないんですよね。

実は、先に縛りを入れておくと態度が変わるんです。

```

賛成も反対もせず、まず私の考えの穴を5つ指摘してください。
そのあとで、5つのうち最も致命的なものを1つ選び、

```

最初の「賛成も反対もせず」が効きますし、そのあとに数を指定してるのもわざとなんですよ。

たとえば「来期から週報をやめたい」みたいな社内の提案でも、この形はそのまま使えるんですよ。

賛成も反対もせずと縛ってから聞くと、上司に言われそうな反論が先に手元に並びます。

5つと言うと、ひねり出してでも5つ出してきますけど、3つだと当たり障りのない話で終わることが多いですね。

実際に画面をお見せしますね。

いま「社内の勉強会を月1で始めたい」と入れてみます。

穴が5つ出てきて、そのうち「参加者の業務時間をどう確保するのか」が最も致命的だと返ってきました【収録時実測】。

これ、自分ひとりで考えてると飛ばしがちな論点なんですよね。

たったこれだけで、企画を人に見せる前の壁打ち相手ができます。

たとえば私の場合、5つ出た指摘のうち3つは「それは織り込み済みです」で終わることが多いんですよ。

残りの1つか2つに自分が見落としてた前提が入っていて、そこだけ拾えば元は取れます。

ここも注意点を1つ。

出てきた指摘を全部つぶそうとせず、5つのうち1つか2つ、自分が納得したものだけ直せば十分です。

全部つぶそうとすると、企画が丸くなって面白くなくなります。
