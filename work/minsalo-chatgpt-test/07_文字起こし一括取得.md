# 文字起こしを一括で取る手順

## なぜトオルさんのPCでやるのか

このセッションからは `youtube.com` がネットワークポリシーで遮断されている（CONNECTに403）。
curl・Chromium・WebFetch のいずれも同じ結果で、回避手段はない。

**トオルさんのPCからは普通に見える。** そちらで取得だけ済ませて、
解析はこちらでやるのが最短。

---

## いちばん簡単な方法：1コマンドで全部やる

リポジトリを手元に clone してあるなら、これだけで済む。
字幕の取得 → タイトル一覧の取得 → `refs/` へ配置 → コミット → プッシュ まで通しでやる。

```bash
pip install -U yt-dlp
bash tools/fetch_transcripts.sh
```

既定では、テスト発注で指定された3本＋「ひかりのAI大学」「ここなのAI大学」の
直近15本ずつを取りに行く。本数や対象を変えたいとき：

```bash
COUNT=30 bash tools/fetch_transcripts.sh
bash tools/fetch_transcripts.sh "https://www.youtube.com/@あかりのAI大学/videos"
```

プッシュまで終われば、セッション側で `style_extract.py` を回せる。

**以下は、手で細かく制御したい場合の手順。**

---

## 1. yt-dlp を入れる（初回のみ）

```bash
# Mac
brew install yt-dlp

# Windows
winget install yt-dlp

# Python があるなら共通
pip install -U yt-dlp
```

---

## 2. 字幕だけ落とす（動画はダウンロードしない）

`--skip-download` を付けるので、**動画ファイルは落ちない。字幕テキストだけ**取れる。

### チャンネルまるごと

```bash
mkdir -p refs && cd refs

yt-dlp \
  --skip-download \
  --write-subs --write-auto-subs \
  --sub-langs "ja,ja-orig" \
  --sub-format vtt \
  --playlist-end 20 \
  -o "%(channel)s_%(upload_date)s_%(title).60s.%(ext)s" \
  "https://www.youtube.com/@ひかりのAI大学/videos"
```

| オプション | 意味 |
|---|---|
| `--skip-download` | 動画は落とさない。**必ず付ける** |
| `--write-subs` | 手動字幕（**句読点があるので精度が高い**） |
| `--write-auto-subs` | 自動字幕（手動がない動画のフォールバック） |
| `--playlist-end 20` | 新しい順に20本まで。全部取ると時間がかかる |
| `-o` | ファイル名にチャンネル名と日付を含める |

### 個別の動画（指定された3本）

```bash
yt-dlp --skip-download --write-subs --write-auto-subs \
  --sub-langs "ja,ja-orig" --sub-format vtt \
  -o "%(title).60s.%(ext)s" \
  "https://youtu.be/9v2_Znxjw4s" \
  "https://youtu.be/nLwBLbySqUc" \
  "https://youtu.be/nh22clwOA9U"
```

### 何が取れるか先に見たいとき

```bash
yt-dlp --list-subs "https://youtu.be/9v2_Znxjw4s"
```

`ja` があれば手動字幕あり（高精度）。`ja-orig` や `ja (auto-generated)` だけなら自動字幕。

## 3. リポジトリに置いてプッシュ

```bash
cp *.vtt <このリポジトリ>/work/minsalo-chatgpt-test/refs/
cd <このリポジトリ>

git push -u origin claude/chatgpt-mastery-test-order-bf485z
```

> `refs/` は `.gitignore` に入れてあるので `-f` が必要。

**Googleドライブに置いてもよい。** その場合はこちらのDrive連携から読める。

## 4. 解析する（こちら側）

```bash
python3 tools/style_extract.py refs/ --out refs/style.md
python3 tools/style_extract.py refs/ --per-file        # 動画ごとの内訳も見る
```

出るもの：

- 一文の長さの分布（平均・中央値・最長・**変動係数**）
- 語尾ランキング上位10と比率
- ですます / だ・である の比率
- 視聴者の呼び方（みなさん・あなた 等）とその回数
- フィラー（えー・なんか・やっぱり 等）の使用状況
- 数字の出現密度
- 冒頭8発話（`--per-file` 時）
- **これらから導いた「台本を書くときのルール」**

## 精度についての注意

**手動字幕（`ja`）と自動字幕（`ja-orig`）では精度がまるで違う。**

自動字幕には句読点がない。そのため行の区切りを1発話として扱うしかなく、
一文の長さと語尾の数値が実際とずれる。
語尾ランキングに「…PTの」のような文の途中が混ざるのはこれが原因。

スクリプトは自動字幕を検出すると警告を出すようにしてある。

**手動字幕がある動画を優先して集めるのが望ましい。**
ただし個人チャンネルは自動字幕のみのことが多いので、
その場合は「傾向を掴む参考値」として読む。

## 何本集めればいいか

**文体の型を取るだけなら5〜10本で十分。** それ以上は数値が動かなくなる。

一方で、以下を見たいなら多いほうがいい。

| 見たいもの | 必要本数 |
|---|---|
| 文体・語尾・呼びかけの型 | 5〜10本 |
| 冒頭フックのパターン | 10〜15本 |
| タイトルの付け方の傾向 | 30本以上（字幕は不要、タイトルだけでよい） |
| 伸びている題材の傾向 | 全部（再生数も併せて取る） |

タイトルと再生数だけなら字幕より軽く取れる。

```bash
yt-dlp --flat-playlist --print "%(view_count)s\t%(upload_date)s\t%(title)s" \
  "https://www.youtube.com/@ひかりのAI大学/videos" > titles.tsv
```

**この `titles.tsv` は非常に有用。** どの題材が伸びているかが一目で分かるので、
「ChatGPT完全攻略」をどの切り口に寄せるかの判断材料になる。
