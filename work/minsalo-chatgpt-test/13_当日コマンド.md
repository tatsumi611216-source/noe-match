# 当日コマンド（PowerShellに2回貼るだけ）

## ブロック1：初回のみ（貼ったら、終わってからターミナルを閉じて開き直す）

```powershell
winget install ffmpeg
irm https://claude.ai/install.ps1 | iex
```

## ブロック2：本番（新しいターミナルで貼る）

```powershell
cd C:\Users\tatsu\noe-match
git pull origin claude/chatgpt-mastery-test-order-bf485z
powershell -ExecutionPolicy Bypass -File work\minsalo-chatgpt-test\tools\setup_studio.ps1
Get-Content -Raw -Encoding UTF8 "work\minsalo-chatgpt-test\11_貼る用プロンプト.txt" | Set-Clipboard
$env:Path = [Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [Environment]::GetEnvironmentVariable("Path","User")
ffmpeg -version
cd $env:USERPROFILE\daihon-studio
claude
```

## ブロック2が終わったら

1. claude が起動して入力待ちになる
2. **Ctrl+V**（プロンプトはもうクリップボードに入っている）→ Enter
3. あとは許可を求められたら承認するだけ。録画開始→執筆→文字数リカバリ→録画停止まで自動

## 補足

- 4行目でプロンプト全文をクリップボードに積んでいるので、メモ帳は不要
- 5行目はPATHの再読み込み。ffmpegインストール直後でもターミナルを
  開き直さずに動かすための保険（ブロック1の直後でも効く）
- 6行目の `ffmpeg -version` でバージョンが出なければ、そこで止めて
  ターミナルを開き直してからブロック2をもう一度
- claude の初回起動はログインを求められる（ブラウザが開く）。1回だけ
