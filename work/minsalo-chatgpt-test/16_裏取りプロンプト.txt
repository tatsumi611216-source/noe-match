# 手順0：まず画面録画を開始する

これから行うファクトチェック作業を録画します。

1. ffmpeg -version で確認。使えなければ止まって私に知らせてください
2. バックグラウンドで録画開始：
   ffmpeg -f gdigrab -framerate 12 -i desktop -pix_fmt yuv420p rec2.mkv
3. 録画が始まったのを確認してから、次へ進んでください

# 依頼：台本のファクトチェック

このフォルダの script_本番.md 内の【要確認：…】タグ全件を裏取りしてください。

# 絶対のルール
- あなたの知識で判定しない。**必ずWebFetchで一次ソースを開いて**、
  ページに書いてある内容とだけ突き合わせる
- 一次ソースは OpenAI公式のみ：
  - https://help.openai.com/en/articles/6825453-chatgpt-release-notes
  - https://help.openai.com/en/articles/9624314-model-release-notes
  - https://openai.com/chatgpt/pricing/
  - help.openai.com 内の各機能のヘルプ記事（検索して辿ってよい）
- インボイス制度の1件だけは国税庁（nta.go.jp）を一次ソースとする
- まとめサイト・ブログ・ニュース記事は開かない
- このフォルダの script_本番.md と facts_verified.md 以外のファイルを
  開いたり、ディレクトリ一覧を表示したりしない

# 手順
1. script_本番.md の【要確認】タグを全件リストアップする
2. 1件ずつ一次ソースを開いて照合する
3. 結果を facts_verified.md に表で書き出す。
   列：タグ内容／判定（✅一致・❌不一致・⚠️確認不能）／根拠URL／
   ページ内の記述の原文引用／確認日時
4. 判定にもとづいて script_本番.md を編集する：
   - ✅ → タグだけ外す（本文は触らない）
   - ❌ → 本文を正しい内容に直してタグを外す。修正前後を台帳に記録
   - ⚠️ → その文の先頭に【削除候補】を付ける。勝手に削除しない
5. ✅❌⚠️の件数と、❌の一覧を報告する

# 手順（最後）：録画を止めて納品ファイルにする

1. ffmpeg のプロセスを停止する
2. ffmpeg -i rec2.mkv -c copy "ChatGPT完全攻略_ファクトチェック録画.mp4" で変換
3. 同じフォルダに ChatGPT完全攻略_ClaudeCode操作録画.mp4 があれば、
   2本を連結して "ChatGPT完全攻略_ClaudeCode操作録画_完全版.mp4" を作ってください。
   連結の中間ファイル（リストファイル等）は半角英数の名前を使うこと。
   連結がうまくいかなければ、無理せず2本のままでよいです
4. できたMP4のファイル名とサイズを報告してください
