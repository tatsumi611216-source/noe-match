# マスタープロンプト — エッセンス注入型ライティングプロンプト

構成は2枚建て。

- **A面**：録画で実際に打つ短いプロンプト。重い制御は `.claude/skills/daihon` と
  CLAUDE.md に常駐しているので、画面上はこれだけで品質が出る
- **B面**：スキルが無い環境（素のChatGPT等）でも同等品質を狙う、全部入りの単体プロンプト

---

## A面：録画で打つプロンプト（この2つだけ）

### A-1 執筆

```
refs/style.md の文体実測と 08_技法カタログ.md の技法に従って、
02_構成案.md の章立てで「ChatGPT完全攻略」の台本を書いてください。

- まず章3だけ。他の章は書かない
- 事実・数値・固有名詞は断定せず【要確認】を付ける
- 書き終えたら tools/ai_smell.py で検査して結果を見せる
- 修正案は出さない。指摘だけ出して止めてください。直すのは私です
```

### A-2 検品

```
draft/初稿.md を tools/ai_smell.py で検査し、
判定と、耳で聞いてつっかえそうな箇所を3つだけ挙げてください。
直さないでください。
```

> 録画でこれが効く理由：短い指示で高品質が出る＝**環境を作り込んでいる人**に見える。
> 実際、制御はスキル層でかかっている。見せる指示と効かせる指示の分離。

## B面：全部入り単体プロンプト（スキル無し環境用）

```
あなたはYouTube教育チャンネルの放送作家です。以下の仕様で動画台本を書いてください。

# 題材と分量
- テーマ：ChatGPT完全攻略
- 10,000文字前後、想定30分
- 視聴者：ChatGPTを検索代わりに使っている社会人。専門用語は通じない

# 文体（実在チャンネル31本・288,296字の実測に基づく）
- 完全な話し言葉。ですます調。「読む文章」ではなく「聞く文章」
- 一文は平均40字、10〜80字で長短を揺らす。80字超は禁止
- 語尾は「〜すよね」「〜んです」を軸に回し、同じ語尾を3連続させない
- 呼びかけは「皆さん」。3発話に1回は具体的な数字を入れる
- 接続は「実は」「ちょっと」「逆に言うと」「で、」

# 構成の型
- 冒頭はコールドオープン：挨拶の前に、得か損を3文以内で言い切る
- 「今日は◯つ」と総量を先に約束する
- 各項目は6ステップの定型で回す：
  ①「◯つ目は【名前】です」②一言定義 ③共感の問いかけかリスク提示
  ④実演（「実際に画面をお見せしますね」）⑤「たったこれだけで〜」の効能確認
  ⑥注意点か、似た概念との区別
- 変わりやすい名前・価格は役割で教える（「名前はよく変わるので3つの役割で覚えてください」）
- 締めは要点の復唱と「今日やること1つ」の指定。「いかがでしたか」は禁止

# 一般ライティング原則
- 結論を先に、理由と例を後に
- 1文に情報は1つ。抽象を2文続けたら具体例を入れる
- 読者がすでに知っていること（ChatGPTとは何か）は説明しない

# 禁止表現
「〜ではないでしょうか」「〜と言えるでしょう」「いかがでしたか」「参考になれば」
「本記事では」「まとめると」「重要です」「〜が求められます」「近年」「様々な」
「革新的」「シームレス」。「活用」「実現」は具体的な動詞に置き換える

# 事実の扱い
- 知識で事実を断定しない。日付・価格・機能名には必ず【要確認】を付ける
- 出典が不明な情報はぼかして書かず、削る

# 進め方
- 一度に全部書かず、指定された章だけを書く
- 書き終えたら、声に出して読んでつっかえそうな箇所を3つ挙げる。修正はしない
```

## 使い分け

| 場面 | 使うもの |
|---|---|
| このリポジトリでの執筆・録画 | **A面**（スキルが効いている前提） |
| 素のChatGPT・他環境でのデモ | **B面** |
| 継続案件で別チャンネルの型に変える | B面の「文体」「構成の型」を新しい実測に差し替え |

継続案件が来たら：新チャンネルの字幕→ `style_extract.py` →実測値でB面を差し替え。
**このパイプラインごと使い回すのが、この道具箱の本当の価値。**

## GPTを工程に挟む場合の注意（2026-08-22 追記）

想定フロー：Claude執筆 → GPT → 人の仕上げ。

**GPTの役割は「書き直し」ではなく「検品」にする。** 書き直させると、
実測に寄せた型（語尾比率・文長の揺らぎ・リフレイン・数字密度）がGPTの平均文体に
引き戻され、禁止表現が復活し、【要確認】タグが消えるか捏造で埋まる危険がある。

### GPT検品用プロンプト（指摘のみ）

```
以下はYouTube台本の草稿です。書き直さないでください。
「AIが書いたと感じる箇所」を10個、番号付きで挙げてください。
各指摘には、なぜそう感じるのかの理由を1行添えてください。
文体の好みの指摘は不要です。定型臭・不自然な均一さ・実感の無さに絞ってください。
```

### どうしても成形させる場合の条件（全部必須）

1. B面プロンプトの全ルールを一緒に渡す
2. 一括ではなく章ごとに処理する
3. 「【要確認】タグは一字も変えずに残すこと」と明記する
4. 戻ってきたら必ず `tools/ai_smell.py` を再実行し、判定B以上を確認する
5. 最後の人の工程（体験談の注入・音読・裏取り）は省略しない。
   AI臭の最終正体は文体ではなく実体験の不在であり、そこはAIには埋められない
