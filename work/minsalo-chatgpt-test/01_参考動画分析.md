# 参考動画・チャンネル分析

## 重要な前提

**この作業環境からYouTube（youtube.com / youtu.be）へのアクセスは遮断されており、
指定3動画の内容を直接確認できていない。**
以下のチャンネル情報は公開Web検索から得た二次情報であり、動画本体の分析ではない。

→ **動画3本は必ず自分の目で見ること。** 下の「型抽出シート」を埋めながら見る。

## ここから読める全体傾向

- 3チャンネルとも **「初心者向け」×「顔出し女性パーソナリティ」×「AI大学」** の統一フォーマット
- ひかり＝業務効率／ここな＝副業収益 と **訴求の軸が分かれている**
- → **どのチャンネル向けの台本かで、同じ「ChatGPT完全攻略」でも中身が変わる**

**先方に確認すべき最重要点：この台本はどのチャンネル向けか。**
確認が取れない場合は、3チャンネルの最大公約数である
**「初心者向け・業務効率・実演ベース」** に寄せるのが安全。副業/稼ぐ系に振ると外す危険がある。

## 文字起こしを取ったあとの解析プロンプト

動画の文字起こしを `refs/transcript_◯◯.txt` に保存してから、Claude Codeで以下を実行する。
（このプロンプト自体、録画で見せると「型を分析してから書いている」証拠になる）

```
refs/transcript_hikari.txt はYouTube動画の文字起こしです。
これから同じチャンネル向けの台本を書くため、文体と構成の「型」を抽出してください。

以下を、必ず本文からの引用を添えて出力してください。推測で補わず、
本文に根拠がない項目は「判断不能」と書いてください。

1. 冒頭60秒の構造を、1文ずつ「何の役割の文か」でラベリング
2. 一文の文字数の分布（平均・最短・最長・中央値）
3. 語尾の出現回数ランキング上位10
4. 視聴者への呼びかけ表現とその出現箇所
5. 章の切り替わりと判断できる箇所、およびその直前直後の定型句
6. 具体例・数字・固有名詞が出てくる密度（何文に1回か）
7. この文体を再現するための「書き手向けルール」を10個、命令形で

出力は refs/style_hikari.md に書き出してください。
```
