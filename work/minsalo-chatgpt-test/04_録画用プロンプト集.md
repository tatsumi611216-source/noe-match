# 録画用プロンプト集（表向き）

## この資料の目的

評価観点②は「**指示（プロンプト）出しから生成物のファクトチェック・リライトまで一貫して行える**」。
つまり先方が見たいのは **出力の質ではなく、工程の質**。

したがって録画では、以下の3つが画面に映っている必要がある。

1. **制約を積んだ指示を書いている**（丸投げしていない）
2. **出力を疑って検証している**（鵜呑みにしていない）
3. **自分の手で直している**（AI任せにしていない）

以下のプロンプトは、この3点が自然に映るように順番が組んである。
**実際に動くプロンプトなので、そのまま使える。**

---

## 事前準備：CLAUDE.md を置く（30秒・録画の冒頭で見せる）

作業ディレクトリに `CLAUDE.md` を置いておくと、
**「毎回同じ指示を書かなくていいように環境を作っている人」** に見える。効果が大きい割に手間はゼロ。

```markdown
# このプロジェクトについて

YouTubeチャンネル「◯◯のAI大学」向けの動画台本を制作する。

## 出力の絶対ルール

- 台本は「読む文章」ではなく「聞く文章」。声に出して自然に読めない文は書かない
- 1文は原則60字以内。長短のリズムをつけ、同じ長さの文を3つ以上続けない
- 以下の表現は使用禁止：
  「〜ではないでしょうか」「〜と言えるでしょう」「いかがでしたか」
  「本記事では」「まとめると」「重要です」「〜が求められます」「活用」「実現」
- 体言止めは1章につき2回まで
- 事実・数字・固有名詞を書くときは、必ず出典URLを併記する
- 出典が確認できない情報は書かず、「【要確認】」とだけ書いて止める

## やってはいけないこと

- 私が渡していない情報を、それらしく補完すること
- 「一般的に」「多くの場合」で具体性を回避すること
- 章の文字数を機械的に揃えること
```

**録画での見せ方**：`cat CLAUDE.md` を1回打つだけ。読み上げ不要。

---

## P1：参考動画の型を抽出する

> **見せているもの**：書き始める前に、対象チャンネルを分析している

```
refs/transcript_hikari.txt は、これから台本を書くYouTubeチャンネルの
既存動画の文字起こしです。

このチャンネルの「型」を抽出してください。私の想像で書くのではなく、
本文から観測できることだけを書いてください。

1. 冒頭60秒を1文ずつに分解し、各文の役割をラベリング
2. 一文の文字数の平均・中央値・最長・最短
3. 語尾の出現回数ランキング上位10
4. 視聴者への呼びかけ表現と、その出現位置
5. 章の切り替わりと判断できる箇所、および直前直後の定型句
6. 具体例・数字・固有名詞の出現密度（何文に1回か）

各項目には本文からの引用を必ず添えてください。
本文に根拠がない項目は、推測で埋めず「判断不能」と書いてください。

結果は refs/style.md に出力してください。
```

---

## P2：リサーチと裏取り

> **見せているもの**：AIに事実を答えさせず、確認先を出させている（＝AIを信用していない）

```
「ChatGPT完全攻略」というテーマで、2026年8月時点の最新情報をまとめたい。

ただし、あなたの知識で事実を書かないでください。学習データは古い可能性があり、
この分野は変化が速いためです。

代わりに、次の作業をしてください。

1. この台本で「正確さが必要になる項目」を洗い出す
   （例：モデル名、料金、提供終了日、機能の対象プラン）
2. 各項目について、私が自分で確認すべき一次ソースのURLを指定する
3. 確認結果を記入するためのチェック表を Markdown で作る
   列は：項目 / 台本に書く内容 / 確認状態 / 一次ソースURL / 確認日

あなたが知識として持っている値がある場合は、
「未確認の参考値」と明記した上で、確認状態の列を必ず ⚠️ にしてください。

出力先は 03_ファクトチェック表.md です。
```

**このあと必ず、ブラウザで公式ページを開いて照合する場面を撮る。** ここが観点③の証拠。

---

## P3：構成を設計する

> **見せているもの**：文字数配分・視聴維持率まで指定している

```
style.md で抽出した型に合わせて、10,000字の台本の構成案を作ってください。

条件：
- 想定視聴者は、無料版ChatGPTをなんとなく使っている社会人
- 視聴後に「設定を1つ変える」という行動を取らせることがゴール
- 章は7つ以内
- 各章の文字数を明記する。ただし均等にはせず、実演パートに全体の4割を配分する
- 各章の冒頭の1文だけ、実際の文面として書く

「ChatGPTとは何か」の説明は入れないでください。
このチャンネルの視聴者はすでに知っています。

各章について、なぜその位置に置くのかを1行で説明してください。
理由が書けない章は削ってください。
```

---

## P4：章ごとに書かせる（1万字を一度に書かせない）

> **見せているもの**：分割して品質を管理している＝量産の実務を知っている

```
構成案の「章3：最初にやる3つの設定」だけを書いてください。他の章は書かないでください。

条件：
- 2,200字前後
- CLAUDE.md の出力ルールを厳守
- 実際にコピペできるカスタム指示の文面を、本文中に1つ入れる
- 事実に触れる箇所には【要確認】を付ける

書き終えたあと、自分の出力を読み返して、
「声に出して読んだときにつっかえる箇所」を3つ挙げてください。
挙げたうえで、直さずにそのまま報告してください。私が判断します。
```

> **最後の2行が効く。** 「AIに直させず自分が判断する」という姿勢が画面に残る。

---

## P5：AI臭を機械検出する

> **見せているもの**：主観ではなく仕組みで品質を担保している

```
tools/ai_smell.py を draft/章3.md に対して実行し、結果を見せてください。
```

実行結果が出たら、続けてこれを打つ。

```
検出された箇所のうち、上位5件について、
「なぜその表現が機械翻訳調・AI調に感じられるのか」を説明してください。

修正案は出さないでください。私が自分で書き直します。
```

> **「修正案は出さないでください」が最大の見せ場。**
> 先方の注意書き「必ず自らの手でチェックすること」に真正面から応えている。

---

## P6：自分でリライトしたあとの検品

> **見せているもの**：人の手が入ったことの確認

```
draft/章3_v1.md（AI生成）と draft/章3_v2.md（私が手で直したもの）を比較してください。

1. 変更された箇所を列挙
2. 各変更について、「読みやすくなったか／崩れたか」を判定
3. 私が直し忘れている、AI調が残っている箇所を指摘

判定は厳しめにしてください。褒めなくていいです。
```

---

## P7：最終検品

```
draft/完成稿.md について、以下を機械的に確認して報告してください。

1. 総文字数（本文のみ。見出しと記号を除く）
2. 章ごとの文字数と、全体に占める比率
3. 一文の文字数が80字を超えている箇所すべて
4. CLAUDE.md の禁止表現の残存箇所
5. 【要確認】が残っている箇所
6. 出典URLが付いていない数字・固有名詞

修正はしないでください。一覧だけ出してください。
```

---

## 録画で「打ってはいけない」プロンプト

これを画面に映すと一発で落ちる。

| NG | 理由 |
|---|---|
| `ChatGPT完全攻略の台本を1万字で書いて` | 丸投げ。観点②の否定 |
| `もっと自然な日本語にして` | 「自らの手でチェック」の放棄 |
| `AIっぽくないように書いて` | AIにAI臭を消させている＝本末転倒 |
| `いい感じにして` | 指示設計力の欠如 |

---

## 録画の尺配分（3〜5分に編集する場合）

| 場面 | 尺 | 何を映すか |
|---|---|---|
| CLAUDE.md を見せる | 20秒 | 環境を作り込んでいる |
| P2 を打つ〜公式サイトで照合 | 90秒 | **ファクトチェック（最重要）** |
| P4 を打つ〜出力 | 60秒 | 制約付きの指示 |
| P5 の実行〜「修正案は出さないで」 | 60秒 | 自分で直す姿勢 |
| 手でリライトしている画面 | 40秒 | 人の手が入っている証拠 |
| P7 の検品結果 | 30秒 | 納品前の検証 |

**合計 5分。** これ以上長くすると見てもらえない。
