# 本番プロンプト — 新セッションに貼る1本（録画用・自己完結）

これ1つで完結する。CLAUDE.mdやスキルが無い環境でも効くように全部入り。
「参考動画から抽出した注意点」を箇条書きで見せる構成なので、
録画を見た人に**動画を分析してからプロンプトを設計した**ことが伝わる。

## 使い方

1. 新セッション（クリーンなフォルダ）でこれを貼る
2. 出力が10,000字に足りなければ、下の「追撃プロンプト」で増量
3. 録画終了。GPT検品と手直しは録画の外で（09の検品プロンプト参照）

## 貼るプロンプト（ここから下をコピー）

```
YouTube動画「ChatGPT完全攻略」の台本を書いてください。

# 仕様
- 10,000文字前後（読み上げ30分想定）
- 視聴者：ChatGPTを検索代わりにしか使えていない社会人。専門用語は通じない
- 章見出しと想定タイムスタンプ付き。Googleドキュメントに貼る前提

# 参考動画3本を分析して抽出した注意点（必ずこの通りに書く）

【話し方】
- 完全な話し言葉。「読む文章」ではなく、耳で聞いてわかる文章
- 一文は40字前後を目安に、10〜80字で長短を揺らす。80字は超えない
- 語尾は「〜すよね」「〜んです」を軸に回し、同じ語尾を3回続けない
- 視聴者への呼びかけは「皆さん」で統一
- 3文に1回は具体的な数字を入れる（分・件数・金額・回数）
- つなぎは「実は」「ちょっと」「逆に言うと」「で、」を使う

【構成】
- 冒頭はコールドオープン。挨拶より先に、得する話か損する話を3文以内で言い切る。
  そのあとに [ジングル] → 「こんにちは、◯◯です」の順
- 冒頭で「今日は◯つ紹介します」と本数を約束する
- 各項目は毎回同じ順番で説明する：
  「◯つ目は【名前】です」→ 一言で定義
  → 「〜ってありますよね」の共感か「実はデフォルトだと〜」のリスク
  → 画面実演（「実際に画面をお見せしますね」）
  → 「たったこれだけで〜」の効果確認 → 注意点か、似た機能との区別
- 項目の切り替えは毎回同じ言い回しにする
- モデル名・料金など変わりやすいものは、名前ではなく役割で覚えさせる
  （例「名前はよく変わるので、早い・じっくり・コード用の3役で覚えてください」）
- 失敗談は動画全体で1〜2回だけ。毎章入れない
- 締めは要点の復唱と「今日やることを1つだけ」の指定。[CTA] マーカーを置く

【禁止】
- 「いかがでしたか」「〜ではないでしょうか」「本記事では」「まとめると」
  「重要です」「近年」「様々な」「革新的」
- 体言止めの連発。箇条書きへの逃げ（台本は語りで書く）

# 事実の扱い
- 日付・料金・機能名・統計は断定せず、すべて【要確認】を付けてください。
  私があとで公式サイトを開いて確認します
- 出典が不明な情報は、ぼかして書かずに削ってください

# 進め方
- 章見出しごとに、最後まで一気に書く
- 書き終えたら総文字数を報告する
- 最後に、声に出して読んだときにつっかえそうな箇所を3つ挙げる。
  修正はしないでください。直すのは私です
```

## 録画後の工程（画面外）

1. GPT検品：09_マスタープロンプト.md の検品プロンプト（指摘のみ・書き直し禁止）

3. 【要確認】の消し込み：03_ファクトチェック表.md の手順で一次ソース照合
4. 仕上げ検査：python tools/ai_smell.py で判定B以上を確認

# 録画込みワンプロンプト版（最小構成・2026-08-22追記）

録画の開始・停止までClaude自身にやらせる版。トオルさんの操作は貼るだけ。

## 事前準備（初回のみ・録画の前に）

```powershell
winget install ffmpeg
```

インストール後、**ターミナルを一度閉じて開き直す**（PATHが通るのは新しいターミナルから）。
`ffmpeg -version` が通ればOK。

デスクトップ全体が映るので、**関係ないウィンドウは全部閉じてから**始めること。
（daihon-studio フォルダで claude を起動していれば映るのはそれだけ）

## 貼るプロンプト（既存の本番プロンプトの先頭にこれを足す）

```
# 手順0：まず画面録画を開始する

台本を書き始める前に、この作業自体の画面録画を開始してください。

1. ffmpeg -version で ffmpeg が使えるか確認する。
   使えなければ、そこで止まって私に知らせてください
2. 次のコマンドをバックグラウンドで実行して録画を開始：
   ffmpeg -f gdigrab -framerate 12 -i desktop -pix_fmt yuv420p rec.mkv
3. 録画が始まったことを確認してから、台本の執筆に進んでください

# 手順（最後）：録画を止めて納品ファイルにする

台本を書き終えて総文字数を報告したら：
1. ffmpeg のプロセスを停止する
2. ffmpeg -i rec.mkv -c copy "ChatGPT完全攻略_ClaudeCode操作録画.mp4" で変換する
3. できたMP4のファイルサイズと保存場所を報告してください
```

## 技術メモ（なぜこの形か）

- 録画は **.mkv で撮って最後に .mp4 へ変換**する。mkvはプロセスを強制終了しても
  壊れない形式。直接mp4で撮ると、停止のさせ方次第でファイルが開けなくなる
- framerate 12 で十分（画面操作の証拠用途）。30分録っても数百MB程度
- コマンド実行のたびにClaude Codeが許可を求めてくる画面も、
  そのまま録画に映る。**それ自体が「本当に操作している」証拠になる**ので消さなくていい
- プロンプトを貼る瞬間だけは録画開始前なので映らない。気になるなら、
  録画開始の報告が出たあとに「今から台本をお願いします」と一言打てば、
  指示を出している画面も映る
