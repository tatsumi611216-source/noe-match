## 手順3：提案アシストを止める（3分）

- [ ] `https://www.lancers.jp/auto_proposal/41807` — 記事作成・ブログ記事・体験談 → **停止**
- [ ] `https://www.lancers.jp/auto_proposal/41290` — パワーポイント・スライド作成 → **停止**

理由は2つ。**A案と逆方向の提案を自動生成し続けていること**と、
**公式案内に「未確認の依頼が一定量を超えると停止します」とあり、放置が機能停止を招くこと**。

止めたうえで、自動化・スクレイピング向けの提案設定を新規に1つだけ作る
（複数作ると確認待ちが溜まって同じことになる）。

## 手順4：パッケージ #2 を出品する（10分・下の文面をそのまま貼る）

最も早く出せて、最も相談が来やすいフロント商品。

**タイトル**
```
【動かなくなった自動化を復旧】スクレイピング・GAS・Pythonツールの修理をします
```

**キャッチコピー**
```
サイト側の仕様変更で止まったツールを、原因調査から修正・再稼働まで3日で対応します
```

**説明文**
```
■ こんな状態のご相談を承ります

・以前作ってもらったスクレイピングツールが、ある日から動かなくなった
・スプレッドシートの自動更新が途中で止まっている
・作った担当者や外注先と連絡が取れず、中身が分からない
・エラーは出ていないのに、取得できるデータが空になっている

■ 対応内容

(1) 現状のコードと実行環境を確認し、動かなくなった原因を特定します
(2) 原因と、修正した場合に再発する可能性を先にご報告します
(3) ご承認後に修正し、実際に動くところまで確認してお渡しします

原因調査の結果、「修理より作り直した方が安い」と判断した場合は、
その旨を正直にお伝えします（その場合、調査までの費用のみ頂きます）。

■ 対応できる技術

Python（requests / BeautifulSoup / Selenium 等）、Google Apps Script、
スプレッドシート連携、定期実行（cron / GAS トリガー）

■ 納品物

・修正済みのコード一式
・原因と修正内容をまとめた報告書（何が起きていたかを日本語で説明します）
・再発しやすい箇所と、その際の対処法

■ 進め方

現在のコード（またはファイル一式）と、エラーメッセージ・実行環境を
お知らせください。まず原因の切り分けからご報告します。

■ お受けできないこと

・対象サイトの利用規約で取得が禁止されている場合の実装
　（着手前に規約とrobots.txtを確認し、不可の場合は公式APIなど別の方法をご提案します）
・ログインが必要な会員制サービス内のデータ取得
・第三者の著作物をそのまま転載する目的での収集

■ 実績

自身で運用するWebメディア（記事200本超）の順位取得・インデックス監視・
品質チェックを、33本のPythonスクリプトで自動化して日次で運用しています。
また、企業の公開求人情報を日次収集して営業リスト化するツールを自作しています
（schema.orgの構造化データと経産省gBizINFO APIを利用し、
有料媒体・会員限定データは対象外とする設計）。
```

**価格・納期**：15,000円／3日
**オプション例**
- 修正後30日間の再発対応保証：+5,000円
- 定期実行環境の再設定（cron／GASトリガー）：+10,000円
- 同種ツールをもう1本追加で修理：+10,000円

**カテゴリ**：システム開発・運用（＋AI関連にも出せるなら併売）
