# 大手が攻められない領域の体系（2026-08-09・25テーマの実測から抽出）

この日、SERPとサジェストを実測したテーマは25件超。勝てたものと負けたものを並べたところ、
判定は好みや勘ではなく**1つの問いに還元できた**。

> **その領域で儲ける事業者が、自社メディアに書く動機を持っているか。**
> 持っていれば入らない。持っていなければ空いている。

大手は「強いから勝つ」のではなく、**書く動機がある場所にだけ現れる**。
だから動機が生まれない場所は、ドメインが弱くても取れる。

---

## 空いている領域の5類型

### 型1. 産業の隙間（2つの業界の境界）

両方の業界が「自分の商材と接続しない」と判断して、どちらも書かない領域。

| テーマ | 隙間の構造 | 実測 |
|---|---|---|
| 一人っ子・親の介護と結婚 | 介護産業は結婚を書かない／婚活産業は介護を書かない | SERPは介護施設と厚労省。**婚活側ゼロ** |
| 長男・跡継ぎ・苗字 | 司法書士は相続しか書かない／婚活は家制度を書かない | 知恵袋・Quora・司法書士。**婚活側ゼロ** |
| 新婚の引越し | ブライダル媒体は式まで／生活媒体は結婚文脈で書かない | 引越し業者のオウンドのみ。比較メディア不在 |
| 新婚のネット回線 | 通信事業者は「引越し」は書くが「2人」は書かない | 本丸はNTT等が占有、2人固有の論点は空白 |

**見つけ方**: 2つの業界にまたがる出来事を探す。結婚・引越し・転職・出産・介護・相続は
すべて複数産業の境界にある。境界の**どちら側の商材とも接続しない論点**が狙い目。

### 型2. 商材に接続しない生活実務

その業界が売るものと関係ない、購入後・入会後の実務。事業者は入会させたいので、
入会しても解決しない話は書かない。

| テーマ | なぜ書かれないか |
|---|---|
| ペットの世話分担・医療費の上限・物件条件 | 相談所の商材と接続しない |
| コレクションの収納・遠征日程・課金の家計処理 | 同上 |
| 回線の名義・解約2件・工事費残債 | 通信事業者は自社契約の話しかしない |

**見つけ方**: 「入会・購入した**後**に発生する面倒」を列挙する。事業者はそこを書かない。

### 型3. 利益相反で書けない

事業者にとって、書くと自社が損する内容。

- 楽天経済圏・ポイント攻略 … 大手金融メディアは利益相反で書けない（上位が全て個人ブログ）
- 「相談所に入らなくていい人の条件」 … 相談所は書けない

### 型4. 知名度が閾値未満のブランド指名

**楽天内でだけ有名**なようなブランドは、比較メディアが個別記事を作る動機を持たない。

| ブランド | SERP実測 |
|---|---|
| ラディアンヌ | note個人×3・アメブロ×2のみ |
| tu-hacci（ツーハッチ） | note個人×2・アメブロ・はてな |
| ヒツジのいらない枕 | **マイベストが在。知名度が閾値を超えると比較メディアが来る** |

**閾値がある。** 一般知名度が上がると大手が参入するので、
「その業界の外の人が名前を知らない」程度が適温。

### 型5. 匿名質問サイトが上位

知恵袋・なんJ・がるちゃん・Quoraが上位に出る＝**企業が誰も答えていない**。
今日の最強シグナルだった。

- 非正規 結婚 … 反対／知恵袋／なんJ／がるちゃん
- 長男 苗字 … 知恵袋・Quora
- バツイチ 恋愛 … 対象外／難しい
- 業者 見分け方 … 知恵袋

同種のシグナルとして、**モールの生検索結果やフリマの個別出品がSERP上位**も空白を示す
（[[affiliate-blank-spots-2026-08]] で確認）。

## 負ける領域の法則（実測で全滅したもの）

### 法則1. その語がどこかの業界の集客キーワードになっている

| テーマ | 誰が占有していたか |
|---|---|
| 結婚 転職 タイミング | 転職エージェント（Geekly・Re就活・type女性） |
| 転勤族 婚活／奨学金 結婚 | 結婚相談所（IBJ・ツヴァイ・サンマリエ） |
| 結婚指輪 金属アレルギー | ブライダルポータル（ウェディングニュース・ウェディングパーク） |
| 結婚内祝い 職場 | ギフトメディア（シャディ・伊勢丹・TANP） |
| 同棲 引越し 費用 折半 | **引越し侍のオウンド**（＝自社の広告主が競合） |

**婚活の「悩み」は相談所の集客語**。属性を変えても同じ顔ぶれが出る。
転勤族も奨学金も年収も年齢も、全部相談所が入会訴求に使っている。

### 法則2. カテゴリ名クエリ（一般名詞）は全滅

| クエリ | 占有 |
|---|---|
| リカバリーウェア おすすめ | OZmall・マイナビ・ティップネス |
| 汗ジミ防止Tシャツ | ベルメゾン・デサント・キナリノ |
| 2人暮らし 冷蔵庫 | アイリスオーヤマ・SUUMO・ヤマダ・ヨドバシ・ビックカメラ |
| 2027年 手帳 | bestcalendar（専業） |

大手はカテゴリ単位でしか記事を作らない。裏を返せば**個別ブランド名は空く**（型4）。

### 法則3. YMYLと制度系

- いびき → 睡眠時無呼吸症候群。歯科・クリニックが占有。薬機法リスクも
- 制度・法改正 → 社労士・税理士のコラムが即占有

### 法則4. 未来イベントも専業ドメインが立つ

GREEN×EXPO 2027・福袋2027・Galaxy S27 はいずれも**専業ドメインが既に稼働**していた。
「まだ先だから空いている」は成立しない。

## 判定手順（この順序を守る）

### ステップ1. 需要のゲート（`scripts/serp_screen.py`）

サジェストが出るか。**出なければ書かない。**

これを飛ばすと最悪の失敗をする。**空白には2種類ある。**

- 誰も気づいていない空白 … 取りに行く価値がある
- **誰も書かない理由がある空白** … 検索されていないだけ

Dark Angel は楽天の年間ランキング上位・レビュー26万件で、SERPに解説記事が1本も無かった。
「最強の空白シグナル」と判断したが、主力商品名の検索ボリュームは**測定不能**だった。
楽天内で売れることと、Googleで指名検索されることは別物。**見た目では区別できない。**

### ステップ2. 誰が上位にいるかを見る（SERP実測）

上位の顔ぶれを業種で分類する。

| 上位の顔ぶれ | 判定 |
|---|---|
| 知恵袋・なんJ・がるちゃん・Quora | **◎ 企業が答えていない** |
| 事業者の自社LPのみ（比較記事が不在） | **◎ 中立の枠が空いている** |
| note個人・アメブロ・はてな | ○ ドメイン勝負になっていない |
| 業界大手のオウンドメディア | **× 集客語。入らない** |
| 量販店・メーカー | **× カテゴリ名。入らない** |
| 医療機関・士業 | **× YMYL。入らない** |

### ステップ3. その業界に書く動機があるかを自問する

上の表で判断できないときの最終判定。

> **この記事の読者が取る行動で、その業界の誰かが儲かるか。**
> 儲かるなら、その業界が既に書いている。儲からないなら空いている。

ペットの世話分担を読んだ人は相談所に入会しない。だから相談所は書かない。
結婚を機の転職を読んだ人はエージェントに登録する。だからエージェントが書いている。

## 過剰な読み取りへの戒め（2026-08-09に実際にやった失敗）

**サンプル1件で結論を出さない。** この日、地域ガイド6本を
「大阪は写真」「仙台は要注意人物」という都市ごとの差を根拠に書き換えた。
根拠は1都市1クエリ・候補4〜8件だけだった。

12都市で測り直したところ、**地域差は存在しなかった**。
写真は9都市、要注意人物は6都市、カフェは6都市に出る全国共通のパターンだった。
6本とも差し戻した。

同日、断定して外したものが他に4件ある（ゲーム機買取・金属アレルギー指輪・内祝い・Dark Angel）。
**いずれもサンプルが少ない段階で結論にした。**

- サジェスト1件は仮説であって結論ではない
- 差を主張するなら、比較対象を複数取ってから言う
- 「実際に検索されているのは〜」と書くなら、その根拠を持っていること
