# アフィリエイト案件の空白マップ（2026-07-30調査）

アフィリエイトリンクが1本も無い51本を、既存の提携案件で埋められるか／新規申請が要るかで分類した。
台帳は `agent/AGENT.md`「アフィリエイトリンク台帳」。

## 結論を先に

- **既存案件で埋められる：約30本**（ほぼ婚活アプリ・動画配信・引越し系の文脈）
- **新規申請が必要：13本**（下記A〜G）
- **収益化しない方がよい：8本**（大手アプリ記事＝流入役・YMYL上限・ステマリスク）

**最も損をしているのは妊活サプリ4本**。商品名レビュー記事を書いているのに
その商品の案件を持っていないため、記事の存在意義そのものが成立していない。

## 新規申請が必要なジャンル（優先度順）

### A. クレジットカード（4本）★最優先

| 記事 | 内容 |
|------|------|
| fuufu-credit-kanri | 夫婦のクレカは家族カードか別々か |
| gosyugi-shiharai-houhou | ご祝儀・結婚式費用のクレカ払い |
| shinkon-ryokou-credit | 新婚旅行の支払いに得なカード |
| futari-kouza-kanri | 結婚後の口座・お金の管理 |

**なぜ最優先か**：記事が4本そろっていて内部リンクも組めており、受け皿として完成している。
カード案件はA8に多数あり、単価8,000〜12,000円級・成果地点が「無料発行」で
成約しやすい。AGENT.mdの案件選定基準（単価×承認率×成約しやすさ）で最も期待値が高い。

**注意**：カードは金融商品なのでYMYL寄り。年会費・還元率・付帯保険は
必ず公式確認を促し、断定しないこと。既存の「クレカリ賃貸」（手数料3.6%で
ポイント還元は赤字になる事実を隠さず書く）と同じ姿勢を保つ。

### B. 妊活サプリ（4本）★取りこぼしが最も大きい

| 記事 | 内容 |
|------|------|
| mitas-formen-kuchikomi | mitas for men の口コミ・成分検証 |
| mitocore-kuchikomi | ミトコア300mgの口コミ・成分検証 |
| myseed-kuchikomi | マイシードの口コミ・成分検証 |
| dansei-ninkatsu-guide | 男性の妊活準備ガイド（ハブ記事） |

**商品名を指定したレビュー記事を3本書いているのに、その商品の案件を1つも持っていない。**
検索する読者は購入意図が明確なので、案件さえあれば最も成約に近い層。

**注意**：健康食品のため薬機法を厳守すること。既存記事は「効能を語らない」構成
（口コミの読み方／成分表示の読み方／継続コスト設計）で作られているので、
案件を入れてもこの方針は変えない。妊娠・効果の断定表現は禁止。

### C. ブライダルインナー・下着EC（1本）
`bridal-inner-guide`。式場・前撮り（ハナユメ）は提携済みだがインナーは別ジャンル。
単価は低いが競合が薄い。

### D. 在宅ワーク・スキル講座（1本）
`kosodate-zaitaku-guide`。レバウェル看護は看護師限定のため使えない。
オンラインスクール系は単価が高い一方、AGENT.mdの広間口ルール
（転職ノウハウそのものは深掘りしない）に触れないよう、
「結婚・子育てを機の働き方見直し」の文脈に留めること。

### E. 住宅ローン比較（1本）
`kekkon-jutaku-loan`。**YMYL厳格領域**。AGENT.mdのクラスタ上限（5〜8記事）と
CTA上限（3箇所）を守り、特定商品の推奨と読める表現は禁止。優先度は低くてよい。

### F. 弁護士・離婚相談（2本）
`rikon-okane-genjitsu`・`koninhiyou-guide`。**YMYL厳格領域**。
単価は高いが、AGENT.mdは既に「財産分与の文脈で買取を勧めるのは印象を損なう」と
判断してリファスタを離婚記事から外している。同じ理由で、離婚記事への
弁護士CTAが「不安につけ込む」形にならないか慎重に判断すること。**保留を推奨**。

### G. 国際結婚・ビザ行政書士（1本）
`kokusai-kekkon-guide`。案件自体が少ないジャンル。優先度は低い。

## 収益化しない方がよい記事（8本）

- **ハブ記事**（matching-app-ranking・konkatsu-roadmap 等）：AGENT.mdの
  「大手アプリ記事の役割定義」により、KPIは収益記事への送客。CTAを増やす対象ではない
- **YMYL上限に達しているクラスタ**：保険・探偵・離婚は既存記事で上限（3箇所）に近い
- `nashikon-data`（結婚式をしない選択の記事）に式場案件を置くのは記事の主張と矛盾する

## 申請時の確認事項（AGENT.mdの選定基準）

　期待値 ＝ 単価 × 承認率 × 成約しやすさ（無料登録＞資料請求＞有料契約）

- 承認率が公表されている案件を同単価帯で優先する
- 同一サービスが複数ASPにある場合は単価と承認率の両方を比較する
- 提携できたら AGENT.md の「アフィリエイトリンク台帳」に
  **リンクURL・使用ルール・置いてよい記事・1記事あたりの上限**を必ず追記すること
  （台帳に無い案件を記事に置くのは禁止）
