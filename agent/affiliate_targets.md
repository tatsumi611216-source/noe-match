## 申請の進め方（A8.net の検索窓に入れるワード）

```
ハナユメ / ゼクシィ / 結婚相談所 / 婚活 / 婚約指輪 /
ブライダルエステ / フォトウェディング / マッチングアプリ /
バチェラーデート / 引越し / 婚活写真
```

afb は「婚活」カテゴリを一覧して単価5,000円以上を一括申請するのが早い。

## 運用ルール

- 承認された案件は `AGENT.md` の台帳に追記 → 工場が新記事に自動で組み込む
- 1記事あたりのアフィリリンクは最大4〜5箇所（YMYL評価保護のため）
- Tier 4 の美容・ジム系は必ず「デート準備・ブライダル」文脈に接続する（単体の美容記事は作らない）
- 医療系（AGA・医療脱毛・美容医療）は当面見送り（YMYL最厳格領域）
