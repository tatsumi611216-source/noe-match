## 中心命題

2026年の検索は AI要約（AI Overviews・ChatGPT検索・Perplexity）に食われつつある。
対応は2方向しかない：
1. **AIが要約できない場所で戦う**（体験・個別事情クエリ、触って使うツール）
2. **AIに引用される側に回る**（一次データ・引用しやすい構造・鮮度）＝LLMO

うちの既存資産（実測主義・記事工場・note弾）はほぼ1で、2が未着手。本書は主に2の実装計画。

- **ツールのキャッシュポイント**: シミュレーター=アフィリ枠設置済み。計算機=結果画面（新生活費用）にビジモ光＋引越し・収納系の文脈CTAを追加する（次の実装）。さらにPhase Cに「診断結果をLINEで保存」→LINE私有地の入口化を積む

## 不採用（理由つき・再検討しない）

| 手法 | 理由 |
|---|---|
| 中古ドメイン・PBN・リンク購入・301転生 | ペナルティで本体ごと飛ぶ。SpamBrain検出は強化の一途 |
| 掲示板・SNSステマ | ステマ規制（景表法）の法的リスク。2023年以降は違法 |
| サジェスト操作 | 規約違反。サジェストは「読む」だけ（A6） |
| Q&Aサイト自演 | アカウントBAN＋発覚時のブランド毀損。C4の公式参加のみ可 |
| 年号だけの空更新 | 実データ更新なしのタイトル年号変更はスパムシグナル |

## 本体戦略との整合チェック

- 「主戦場1つに絞る」→ A4計算機・B1-B3改修はすべて主戦場（お金）クラスタ内。分散しない
- 「網羅性・速報性で勝負しない」→ 採用施策はすべて一次データ・ツール・構造の勝負。整合
- 「一般論を実測なしに採用しない」→ A3（AI回答の実測）を他施策の前提に置いた。
  「AIOが出るクエリは0クリック」も**うちのクエリで実測してから**ゲート化する（初回実測でA2の閾値を較正）
- PDCA凍結 → Phase Aは凍結40本のページ・対象クエリに一切触れない構成
