# note SEO弾 執筆スタイルガイド（フェーズ1・2026-08-12）

## 出力形式
- 1行目: `<!--TITLE: タイトル-->`
- 以降: HTML断片（noteエディタへpaste注入する）。使ってよいタグ: h2 / h3 / p / ul / ol / li / strong / a / blockquote
- **表(table)は禁止**（noteエディタは表非対応。比較は箇条書きか「A：〜／B：〜」形式で）
- 文字数: 本文3,000〜4,000字

## タイトル
- **ターゲットクエリの語をそのまま含める**（エッセイ型・問いかけだけのタイトル禁止）
- 32字前後

## 構成
1. 結論を最初の2段落で言い切る（読者の疑問に直接答える）
2. h2は3〜5個。h2ごとに具体論
3. 独自の整理（分類・判断基準・順番）を必ず1つ入れる。一般論の羅列は不可
4. 最後のh2の後に、noe-matchの指定記事への誘導段落（自然な文脈で1〜2本。URLは絶対URL https://www.noe-match.com/articles/スラッグ/）

## 禁止事項（厳守）
- アフィリエイトリンク・広告表現（noteに広告は載せない）
- 効果・成婚・結果の断定（「必ず」「絶対」「〜できます」の保証形）
- 属性（雇用形態・持病・家族構成・趣味・体型）を欠点や不利として描く表現。
  「条件を先に共有できる場を選ぶ」という構造の説明として書く
- 医療・法律の助言（一般論と「専門家・公的窓口で確認」の線を守る）
- 架空の人物名の体験談（「◯◯さん（32歳）」形式は使わない。編集部の整理・読者から見える実例の型として書く）
- 「参考記事」「詳しくはこちら」だけの雑なリンク（前後に文脈を書く）

## トーン
- noe-match本体と同じ実務調。煽らない。不安を増幅して売る構成は禁止
- 読者は悩みの当事者。突き放さず、かといって同情で薄めない
