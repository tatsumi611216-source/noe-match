## この日に増えた知見

- **生成スクリプトに他媒体のアフィリURLが混入することがある。** 24ページ・90箇所が
  `45C0YR`（台帳外の媒体ID・飛び先は coreda.jp）だった。台帳に載っていない `a8mat` の
  先頭ブロックが出てきたら、その時点で異常とみなす。`factory_audit` はリンクの有無しか見ておらず、
  **どの媒体IDか・飛び先が文言と一致するかは検査していない**（検査の追加候補）
- **アフィリリンクに id が無いと、GA4のclickは案件も位置も判別できない。** 新規CTAを置くときは
  必ず `id="aff-..."` を付ける（`result_clicks.py` は `aff-` 始まりを主KPIとして数える）
- **平均順位は表示と並べて読む。** 9/19〜9/20に平均12〜14位まで上がったのは、共働き記事の表示が
  日31→日1に落ちて下位帯が消えたため。30位より下の表示の割合は29%→10%、クリックは2.5件/日で不変
- **GSCは検索流入の35%しか見ていない。** Bing 23%・AI 17%（`scripts/channel_mix.py --days 28`）
- **public リポジトリに有料商品を置きかけた。** `agent/product_drafts/kosodate_23ku_2026/_dist/`（PDF・CSV）は
  `agent/` 配下＝追跡対象のディレクトリにあり、次に `git add -A` した時点で ¥1,980 の商品が無料公開される
  ところだった。`.gitignore` の `products/` は実際の置き場を指していなかった。**成果物を作る場所は、
  公開リポジトリの追跡対象かどうかを置く前に確かめる。** 検査は `factory_audit` の `audit_repo_leak()` に固定した
