## 方針

**時間で増えるもの（トラフィック）は止めずに回す。時間で増えないもの（転換率）だけに人の判断を投じる。**

生産を止めると、判定に必要なクリックが貯まる日が遠のく。9月の判定対象（タイトル差し替え・
note送客・CTA配置）は新規ページの追加では汚れないので、**固定するのは実験中の変数だけ**。

### 11月｜転換率の初回判定 → **取り下げ（2026-09-04）**

判定に要る250〜300クリックという設計は、**A8の水増しされたクリック数を分母にしていた**。
正しい分母（GA4内蔵click）は**月6件**で、250件に届くのは3年以上先になる。
**アフィリの転換率は、この規模では原理的に測れない。** 11月に判定日を置いても何も出ない。

代わりに11月に見るのは次の2つ。**どちらもトラフィックが小さくても答えが出る。**

| 見るもの | 判定できること |
|---|---|
| 月次セッションの軌道（目標 1,500） | 面を増やす以外の伸ばし方が効いたか |
| 自社商品の販売数（10月出荷） | **転換の証拠。提携先の転換率に依存しない** |

アフィリは「規模が届いたら測る」棚に移す。**測れるようになる条件は月2,000セッション**
（クリック率1.5%なら月30クリック、10か月で300）。それまでは置いておくだけで、
実験の対象にはしない。

## 判断を変える条件

| 観測 | やること |
|---|---|
| 自社商品が11月末までに1本も売れない | 商品ではなく**出口**を疑う（LINE配信0回・note導線が9月開始のため、まだ売り場が立っていない） |
| 自社商品が売れる | 原価ゼロの第2弾へ。バンクの月次差分がそのまま材料になる |
| 発生（A8）が1件でも出る | 婚活側（C・E）に投資を戻す。**ただし1件では何も確定しない**ので、投資は戻すが判定はしない |
| 月2,000セッションに到達 | アフィリを棚から下ろす。ここで初めて転換率の測定を設計し直す |
| **月次トラフィックが2か月連続で横ばい** | **最も警戒すべき兆候。** 空白地帯の在庫切れを疑う |
| 12か月目（2027年5月）に月5,000セッション未満 | そのとき初めて「生産ラインを別ジャンルへ」を検討する |

**別ジャンルへの移設は月3で出す判断ではない。** 複利が効き始めた資産を捨てて振り出しに戻ることになる。
