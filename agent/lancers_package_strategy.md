# ランサーズ パッケージ販売戦略（2026-08-21 策定）

## 前提（本ドキュメントの適用条件）

- **現状**：パッケージは出品済み。ただし相談・受注がほぼゼロ。
- **商材**：①サイト構築・Web制作／②業務自動化・スクレイピング／③AI導入コンサル・研修
- **手持ちの実物資産**：noe-match.com（200本超の記事・GSC連携・記事工場の自動化スクリプト群・
  ブラウザで動く診断ツール/シミュレーター12本）。**これが最大の営業材料**であり、
  「作れます」ではなく「これを作って、この数字が出ている」と言える状態にある。
- **未確認事項**：システム手数料は一律16.5%（税込）とされるが、適用条件と最新改定は
  出金前に管理画面で実額を確認すること。ランク／認定ランサーの審査基準も公式ヘルプで
  都度確認する（本書では基準の断定はしない）。

## 1. 診断：なぜ「出品しても売れない」のか

パッケージ検索の表示順は、おおむね次の要素で決まるとされる。

> 表示数・閲覧数・お気に入り数／相談数と注文率／実績数と評価数／獲得報酬額／
> 返信速度／出品内容の鮮度と充実度（タイトルの具体性、画像点数、動画・PDFの有無）／
> 価格が1万円以上かどうか

ここに構造的な罠がある。**上位表示の要因の大半が「すでに売れていること」**である以上、
実績ゼロのパッケージは検索経由でほぼ露出しない。つまり

> **「良いパッケージを出して待つ」は、この設計上どう頑張っても詰む。**

したがって打ち手の順序は固定される。

```
提案（プロジェクト応募）で最初の受注を取る
   → 実績・評価・獲得報酬が積まれる
      → パッケージの検索順位が上がる
         → 指名相談が入る（ここで初めて「待つ」が機能する）
            → 単価を上げる／月額運用へ移す
```

**パッケージは集客装置ではなく、提案で会った相手に見せる「商品カタログ兼見積書」である。**
この一点を取り違えている限り、説明文をいくら磨いても数字は動かない。

## 2. 商品設計：3階建てにする

現状の典型的な失敗は「本命の1商品だけを出している」こと。買う側は初回に大金を払えない。

| 階層 | 役割 | 価格帯 | 例 |
|------|------|--------|-----|
| **フロント** | 摩擦を消して接点を作る。ここは利益を取らない | 1.5〜3万円 | 業務の自動化余地 診断レポート／既存サイトの改善診断／動かなくなった自動化の修理 |
| **本命** | 実際の粗利源 | 5〜30万円 | サイト制作／定期スクレイピング構築／API組み込み |
| **継続** | 収益の土台。ここを作らないと毎月ゼロから営業 | 月額1〜5万円 | 保守・監視・月次レポート・スクレイパーの仕様変更追従 |

設計ルール:

- **価格は必ず1万円以上**（表示順の要因であり、かつ客層フィルタになる）。
- **手数料16.5%を織り込んで「受取額から逆算」して値付けする**。値引き交渉には
  価格を下げず、オプションを外して応じる。
- **オプションで単価を伸ばす**（追加ページ／収集対象サイトの追加／定期実行のサーバ設定／
  納品後30日の修正保証／保守月額）。本体は入りやすく、合計で伸びる形にする。
- **スクレイピングは「対象サイトの利用規約とrobots.txtを確認し、規約上不可の場合は
  代替手段を提案する」と説明文に明記する。** 断られる案件は先に断られた方が安い。

## 3. パッケージは「1本」ではなく「用途別に20本」出す

同じ実装能力を、**業種 × 困りごと**で切り分けて別商品にする。パッケージ本数は
そのまま検索面の在庫であり、ニッチなキーワードほど競合が薄い。

### サイト構築・Web制作

1. 【士業・治療院・工務店向け】問い合わせフォーム付き5ページのサイト制作（10日）
2. 【1ページ完結】サービス紹介LP制作（スマホ最適化・計測タグ設置込み）
3. **【集客用】Webで動く「診断ツール／シミュレーター」制作（結果分岐つき）** ← 最大の差別化。実物12本あり
4. WordPressから静的サイトへ移行し、表示速度と月額保守費を下げる
5. 〈フロント〉既存サイトの改善診断レポート（表示速度・内部リンク・導線）＋修正見積
6. GA4／サーチコンソールの初期設定＋月次レポートの自動生成

### 業務自動化・スクレイピング

7. 【毎日の手作業を消す】Webサイトからのデータ定期収集＋スプレッドシート自動更新
8. 競合価格の毎日自動収集＋変動アラート（Slack／メール通知）
9. スプレッドシート → Slack／メールの定期レポート自動配信
10. 店舗情報・商品情報の一括収集（CSV納品・件数従量制）
11. 毎月のExcel集計をPythonで自動化（月次締め作業の圧縮）
12. 〈フロント〉**動かなくなったスクレイパー／自動化の修理**（仕様変更対応）

### AI導入コンサル・研修

13. 〈フロント〉【90分】生成AIの業務導入 個別相談（現状ヒアリング＋導入ロードマップ提出）
14. 社内向け ChatGPT／Claude 活用研修（60分×2回・自社業務のプロンプト10本つき）
15. 自社業務用のプロンプト／スキル整備（業務テンプレを納品物として渡す）
16. Claude API／ChatGPT API の業務システム組み込み実装
17. AI記事生成の社内フロー構築（品質チェック手順と禁止事項つき）
18. 〈フロント〉業務棚卸し＋自動化余地の診断レポート（「何ができるか分からない」層向け）

**タイトルの型**：`【誰向け】何を・どうする（納期／条件）`。検索語は必ず前半に置く。
「Webサイト制作します」のような供給側の言葉は捨て、買う側が検索する言葉に置き換える。

## 4. 需要から作る（供給から作らない）

週1回、次を実測して記録する。**思いつきでパッケージを作らない。**

1. ランサーズの案件検索で自分の領域のキーワードを引き、**件数と予算帯**を控える
2. 同キーワードのパッケージ上位20件について、**価格・納期・実績数・オプション構成**を表にする
3. **価格帯の空白**（例：3万円台が誰もいない、即日納品がいない）を狙って新パッケージを出す

案件数が多く、上位の実績数が少ないキーワード＝入り込める場所。ここだけを取りに行く。

## 5. コールドスタートの壊し方（最初の評価5件）

- **提案は1日3件。ただしテンプレ送信はしない。** 冒頭2行で「相手の要件を自分の言葉で
  言い換える」ことだけに集中する。ここを読んだ相手しか返信しない。
- 提案文の型：①相手の課題の言い換え → ②同型の実績（URLと数字） → ③初回は分割納品で
  リスクを下げる提案 → ④確認質問を1つ
- **最初の3件は相場の7掛け＋短納期で、評価とレビュー本文を取りに行く。**
  評価依頼時は「どの点が良かったか」の観点をこちらから指定する（次の客が読む文章になる）。
- ポートフォリオに noe-match.com の実物と診断ツールを登録する。
  **触れるデモがあることは、実績数の少なさを一部代替する。**

## 6. 見せ方（順位要因に直接効く部分）

- 画像は1枚目に**成果物の画面キャプチャ**か**ビフォーアフター**を置く。文字だけの表紙は捨てる
- 動画・PDFを添付する（充実度が順位要因）。30秒の操作画面録画で十分
- 説明文には**見積り例・想定スケジュール・こちらが必要とする素材・FAQ**を書く
- **「対応できないこと」を明記する**（例：デザインのみの依頼、規約上不可のサイトの収集）。
  断る基準がある出品者の方が信用される
- 通知に即応し、**平均返信時間を短く保つ**（順位要因かつ失注要因）
- **30日ごとに全パッケージを更新する**（鮮度が順位要因）。価格・実績・FAQを差し替える

## 7. プラットフォーム外からの流入

パッケージの閲覧数は外部からの流入でも積める。既存資産を営業に転用する。

- noe-match.com のフッターと運営者情報に「サイト制作・業務自動化の依頼」導線を置く
- X／noteで**実装ログ**を出す（「毎朝30分の集計を消した話」など）。作業の過程を出すと
  同じ悩みを持つ発注者が反応する。着地はパッケージURL
- **200記事のサイトを自力で運用しているという事実自体が、Web制作の最強の証拠になる**

## 8. どこで死んでいるかを数字で切り分ける

週次で記録：`表示数 / 閲覧数 / お気に入り / 相談数 / 受注数 / 提案数 / 返信率 / 平均返信時間`

| 症状 | 原因 | 打ち手 |
|------|------|--------|
| 表示数が少ない | キーワード・在庫不足・鮮度切れ | ニッチ語で本数を増やす／全件を更新する |
| 表示はあるが閲覧が少ない | サムネ・タイトル・価格 | 1枚目画像を成果物写真に、タイトルを「誰向け」始まりに |
| 閲覧はあるが相談ゼロ | 説明文の具体性・実績の欠如 | 見積り例・納品物の実物・FAQ・断り条件を追加 |
| 相談は来るが失注 | 初回返信速度・提案の作り | 即応、分割納品、修正保証の明記 |
| 受注はあるが儲からない | 単価設計 | オプション化・月額運用への移行・値引きの停止 |

**判断は数字でのみ行い、「たぶん刺さっていない」で書き換えない。**
