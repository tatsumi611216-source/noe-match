# 令和7年国勢調査 人口等基本集計（2026-09-29公表予定）での統計記事更新チェックリスト

作成: 2026-09-08（順位パケット③の準備）。実行は 9/29 の公表後。
**根拠**: 統計局は令和7年国勢調査の人口等基本集計を2026年9月（全国）に公表予定と告知（8/24更新）。当サイトの生涯未婚率記事は「2026年9月29日公表予定」と明記して公開している。
公表日が動いた場合は、この日付の記述（下記A-4）を先に直す。

## 0. 公表当日にまずやること

1. https://www.stat.go.jp/data/kokusei/2025/kekka.html を開き、「人口等基本集計」が公表されているか確認する。未公表なら**記事は触らず**、A-4の「公表予定」表現だけ実際の予定日に合わせる。
2. e-Stat（統計表ID: 令和7年国勢調査 人口等基本集計）から **配偶関係別・年齢5歳階級別人口（男女別）** を取得する。
3. 生涯未婚率（50歳時未婚割合）を自分で計算する: **（45〜49歳の未婚割合＋50〜54歳の未婚割合）÷2**、男女別。未婚割合＝未婚 ÷（総数−配偶関係不詳）。社人研『人口統計資料集』の更新（通常は翌年）を待たない。計算式と分母の扱いは記事本文の定義節と一致させる。
4. 数字が出たら、下記A→B→Cの順で更新し、**title変更はH1・og:title・twitter:title・ld+json headline・パンくずも揃える**（罠: title変更はH1も揃える）。
