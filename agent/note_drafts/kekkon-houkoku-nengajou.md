# 結婚報告の年賀状、「誰に出さないか」を教えてくれる記事が少ない理由

**タイトル案：** 職場に写真入り年賀状、出していいのか問題の答え

結婚報告はがきを検索すると、出てくるのはほぼ印刷会社のページです。デザインは山ほど紹介されているのに、当事者が本当に迷う「誰に出して誰に出さないか」はあまり書かれていません。出す枚数が減る方向のアドバイスは、印刷会社の立場では書きにくいからです。

実務的な整理はシンプルで、宛先を職場・親族・友人の3グループに分けること。上司や取引先には写真なしが無難、親族や式の出席者には写真ありが喜ばれやすい、式に呼ばなかった友人はLINE報告済みなら省略も一般的、という線引きが基本になります。「全員写真あり」で統一する必要はなく、写真あり/なしの2種類を作り分けて発注するのが現実的です。

文面も、フォーマル（上司向け）・セミフォーマル（親族向け）・カジュアル（友人向け）の3トーンを用意すれば、ほぼ全員をカバーできます。

そして一番間違えたくないのが喪中との重なりです。自分たちが喪中でも相手が喪中でも、年賀状は出さず、松の内明けから立春までの寒中見舞いで控えめに報告するのが一般的な対応。祝い言葉を前面に出さない構成にします。

費用面では、ネット印刷は数十枚で数千円程度から。11月頃までの早期割引で印刷代が2〜4割安くなる例が多いので、逆算すると11月中にはデザインと宛先リストを確定させておきたいところです。

記事では、関係性別の判断表、コピペで使える3トーンの文例、前撮り写真を年賀状に活かす撮り方のコツまでまとめています。
