# 新居の家具、入居前に全部そろえた人ほど後悔しているらしい

新生活の家具・インテリア一式は30万〜60万円程度が一つの目安とされています（結婚・新生活に関する各種調査の公開情報より）。ただしこの数字、そのまま予算にするとずれます。「一度に全部そろえた場合」の金額だからです。

品目別に価格帯を並べ直して気づいたのは、**金額の大きさと緊急度がまったく一致していない**ことでした。

金額の上位はベッド（5万〜25万円）、ソファ（3万〜20万円）、ダイニングセット（3万〜15万円）。この3つで総額の半分以上を占めます。ところがどれも、カタログを見ただけでは決められません。ベッドはダブル1台かシングル2台かで生活が変わり、ダイニングは在宅勤務の有無で必要な天板サイズが変わるからです。

逆に、入居初日にどうしても必要なのはカーテン・寝具・照明の3つだけ。カーテンがなければ夜に照明をつけた瞬間、室内が外から見えます。照明も物件によっては器具が付いていません。金額は小さいのに優先度は最上位です。

つまり家具の予算は、総額を削るより「買う順番」を設計するほうが効きます。式場や指輪と違い、家具には外から決まる支払期日がないからです。

記事では、入居前にソファを買わなかったケースを紹介しています。レイアウト図ではリビングの中央に置く予定だったのに、住んでみたら二人ともダイニングにいる時間のほうが長かった。予算はダイニングチェアのグレードアップに回りました。
