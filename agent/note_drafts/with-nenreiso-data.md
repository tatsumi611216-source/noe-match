# withは「20代向け」と言われるけど、実際の年齢層はどこまでわかるか

withを調べると「20代中心」「若い層向け」という説明をよく見かけます。公式も「20代の利用者が多い」というポジショニングを取っています。でも具体的な数字——「20代が全体の何%」「平均年齢は何歳」——は公式から発表されていません。

公式が出しているのは「会員の多くが20〜30代」という属性の説明であり、細かい年齢分布ではないのです。

では「20代が多い」という認識はどこから来ているかというと、主にwithのサービス設計と心理テスト機能にあると思います。withは「相性を重視する出会い」をコンセプトにしており、心理テストや価値観診断の機能が目立ちます。この設計が恋愛経験を積み重ねている途中の層——つまり20代に刺さりやすく、結果として若い利用者が集まる構造になっています。

30代の利用者がいないわけではありませんが、30代になって「本気で結婚したい」という目的が明確化してくると、成婚実績やサービスの厚みで選ぶ人が増え、Omiaiやユーブライドに流れる傾向があると考えられます。

つまり「withが20代中心」というのは、ユーザーが意識的に選んでいるというより、サービスの設計が20代に選ばれやすくなっているという話です。

30代が使えない、ということはありません。ただ「同年代の会員がどの程度いるか」という点では、自分の年齢・目的と照らして確認しておく価値があります。
