# 家賃のカード払い、手数料を払っているのは実は入居者じゃないという話

「家賃をクレジットカードで払うと手数料を取られるのでは」と思っている方、けっこう多いのではないでしょうか。私も調べ始める前はそう思っていました。結論から言うと、**逆です**。

クレジットカード会社の加盟店規約では、決済手数料を利用者に上乗せして請求することは原則として認められていないとされています（カード各社が公開している加盟店規約の一般的な内容より）。小売店で「カード払いなら3%上乗せ」という扱いを見かけないのと同じ構造です。

つまり、管理会社や貸主が正規にカード決済を導入している物件なら、入居者は**手数料を負担せずポイント還元だけを受け取れる**ケースが多いということになります。月10万円の家賃を還元率1%のカードで払えば、月1,000円相当・年12,000円相当。家賃は多くの世帯で最大の固定費ですから、生活を何ひとつ変えずに得られる還元としては規模の大きい部類です。

ではなぜ普及していないのか。手数料を負担しているのが**貸主側**だからです。家賃8万円の部屋で決済手数料が5%かかると、貸主の実収入は7万6,000円。年間で1戸あたり4万8,000円の差になり、戸数分だけ積み上がります。導入に慎重な貸主が多かった理由はここにあると説明されています。近年は空室対策・滞納リスク軽減の観点から対応する物件も増えているとされます。

ここで大事なのは、**これは入居者が選べる問題ではない**ということ。家賃をカードで払えるかどうかは、物件と管理会社が決めています。だから本質的には「カード選び」ではなく「物件選び」の話になります。

損得の計算が必要になるのは、非対応の物件で決済代行サービスを使う場合だけです。この形式では利用者側が手数料を負担する設計のものがあり、前提がまるごと変わります。判断は「還元率 − 手数料率」がプラスかどうか。手数料率が2%を超えると、一般的な還元率（0.5〜1.5%）ではまず差し引きマイナスになる計算でした。

記事では、手数料率1〜5%×還元率0.5〜1.5%の損益分岐を表にしています。あわせて、意外と見落とされる「初期費用（敷金礼金・仲介手数料）のカード払い可否」についても触れました。数十万円が一括で動く分、月々の家賃より金額インパクトが大きいこともあります。
