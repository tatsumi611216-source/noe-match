# 家賃のカード払い、手数料を払っているのは実は入居者じゃないという話

「家賃をクレジットカードで払うと手数料を取られるのでは」と思っている方は多いかもしれません。結論から言うと、**逆でした**。

クレジットカード会社の加盟店規約では、決済手数料を利用者に上乗せして請求することは原則として認められていないとされています（カード各社が公開している加盟店規約の一般的な内容より）。つまり正規にカード決済を導入している物件なら、入居者は**手数料を負担せずポイント還元だけを受け取れる**ケースが多いということです。月10万円の家賃を還元率1%のカードで払えば、月1,000円相当・年12,000円相当。家賃は多くの世帯で最大の固定費ですから、規模の大きい還元源です。

ではなぜ普及していないのか。手数料を負担しているのが**貸主側**だからです。家賃8万円で手数料5%なら実収入は7万6,000円。年4万8,000円の差が戸数分だけ積み上がります。近年は空室対策・滞納リスク軽減の観点から対応する物件も増えているとされます。

大事なのは、これが入居者に選べる問題ではないこと。可否を決めているのは物件と管理会社なので、本質的には「カード選び」ではなく「物件選び」の話になります。

損得計算が必要になるのは、非対応物件で決済代行サービスを使う場合だけ。この形式は利用者が手数料を負担する設計のものがあり、前提が変わります。判断は「還元率 − 手数料率」。手数料率が2%を超えると、一般的な還元率ではまず差し引きマイナスでした。
