# 公務員がマッチングアプリで「最強カード」を出し損ねている件

**タイトル案：** 公務員の婚活、実はアプリで一番有利なのに一番損しています

婚活市場で公務員は間違いなく人気属性です。安定した職業は、結婚を考える相手にとって分かりやすい安心材料だからです。

ところが実際のアプリでは、公務員の多くがこのカードを出し損ねています。理由は身バレへの恐怖。職業欄を「その他」にしたり、写真を載せなかったり——結果、せっかくの強みが伝わらないまま埋もれてしまう。

実は、身バレ対策と職業アピールは両立できます。職業欄は「公務員」と書きつつ所属や職種は伏せる、顔写真は載せつつ勤務地から離れたエリアで活動する、ブロック機能で職場関係者を先回りして遮断する——手順さえ知っていれば、リスクを抑えながら強みを活かせるんです。
