# 新婚家電、レンタルと購入の分岐点は「1年10ヶ月」でした

**タイトル案：** 家電のサブスク、何年使うと損になるか計算してみました

新生活の家電をレンタルにするか買うか。「長く使うなら買った方が安い」で終わりがちな話ですが、実際に何年目で逆転するのか計算してみました。

前提は冷蔵庫・洗濯機・電子レンジ・テレビの4点セット。購入なら本体が約12万円、レンタルなら月6,000円程度が標準的な水準です（大手量販店・大手家電レンタルサービス公式サイトの公開価格より・2026年7月時点）。

多くの比較が見落としているのが**処分費**です。冷蔵庫・洗濯機・テレビは家電リサイクル法の対象で、捨てるときにリサイクル料金＋収集運搬料金がかかります。3点で1万円前後。これを購入側に足さないと公平になりません。

購入総額を13万円（本体12万円＋処分費1万円）として計算すると、分岐点は約21.7ヶ月。**およそ1年10ヶ月**です。1年時点ではレンタルが5.8万円安く、3年では購入が8.6万円安く、5年では23万円の差になります。

月額が変わると分岐点も動きます。月4,000円なら約2年9ヶ月、月8,000円なら約1年4ヶ月。標準的なプランなら「2年」が境目と考えて差し支えありません。賃貸の更新周期と重なるので、目安として使いやすいはずです。

そして見落とされがちなのが、全点をどちらかに統一する必要はないということ。長く使う冷蔵庫と洗濯機は買い、動かす可能性が高いテレビだけレンタルにする併用が、「まだ何年住むか決まっていない」新婚時点には一番素直に効きます。
