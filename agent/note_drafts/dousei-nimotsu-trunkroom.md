# 同棲で荷物が入らないのは、片づけが下手だからではありません

部屋は1.3〜1.5倍になるのに、収納は2倍になりません。持ち込む荷物だけがきっちり2倍になります。
同棲・結婚で荷物が収まらないのは、この非対称が原因です。

一人暮らし同士が一緒に住み始めると、ほぼ確実に段ボールが数箱余ります。さらに冷蔵庫・洗濯機・電子レンジ・掃除機・カーテンといった重複した家電が追い打ちをかけます。「まだ使えるから」と保留した瞬間、それは部屋を圧迫し続ける存在になります。

行き先は実質3つ、処分・実家預け・トランクルームです。判断で使えるのは、思い入れの大小ではなく金額の比較でした。

月5,000円のスペースを2年借りれば12万円。それより安く買い直せるものは、処分した方が金額的には合理的です。逆に買い直せないもの（写真・書類・記念品）は、そもそも比較の対象になりません。迷わず保管側でいい。

トランクルームの相場は、屋内型で0.5畳が月3,000〜8,000円、1畳が月5,000〜15,000円、2畳が月10,000〜25,000円ほど（各社公式サイトの公開価格帯より・2026年7月時点）。屋外コンテナ型は同じ広さで2〜4割安くなります。ただし価格差の主因はサイズより立地で、都心と郊外では同じ1畳が3倍近く違うこともあります。

そして最大の落とし穴は、契約することではなく解約時期を決めないことでした。月6,000円でも3年で約22万円です。

もうひとつ、揉めないための順序があります。相手の私物から手をつけない。まず重複した共有物を統合する。これだけで収納に余裕が生まれて、私物を減らす議論そのものが小さくなります。荷物の摩擦は量ではなく「誰が誰の物を減らすか」という構図から生まれています。
