# 結婚相談所、実は「高い方が安い」ことがあるという話

**タイトル案：** 結婚相談所の料金、オンライン型と店舗型で10倍差。でも安い方が得とは限らない

結婚相談所を調べ始めると、まず驚くのが料金の幅です。オンライン完結型なら年間10〜20万円、大手の店舗型（仲人あり）だと成婚料込みで30〜50万円。同じ「結婚相談所」という括りなのに、なぜここまで差があるのでしょうか。

答えはシンプルで、差額のほとんどは「人件費」です。店舗型には専任の仲人がついて、相手選び・お見合いの日程調整・交際中の相談・気まずい交際終了の連絡まで代行してくれます。オンライン型はこの仲人業務をシステムとチャットサポートに置き換えることでコストを下げています。

つまり選ぶ基準は「自分でどこまで動けるか」です。相手を探すこと自体が苦にならない人にはオンライン型で十分。誰かに背中を押してもらわないと動けない自覚がある人には、店舗型の差額は妥当な投資になります。

もう一つ知っておきたいのが、連盟(IBJなど)に加盟している相談所は会員データベースを共有していること。つまり「同じ人に、違う価格で出会う」ことが起こり得ます。この場合は安い方を選ぶのが合理的です。
