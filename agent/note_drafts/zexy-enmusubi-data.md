# note下書き｜ゼクシィ縁結びの成婚率

**タイトル案**：「ゼクシィ縁結びの成婚率は公表されていない」——それ自体が価値ある情報である理由

---

婚活アプリを選ぶとき、多くの人が「成婚率が高いアプリ=良いアプリ」と考えます。でも実は、国内の主要マッチングアプリのほとんどは成婚率を公表していません。ゼクシィ縁結びもそのひとつです。

「じゃあ意味ないじゃないか」と思われるかもしれません。でも、私はこの「非公表」という事実を知ることにこそ、大きな意味があると考えています。

ゼクシィ縁結びを運営しているのはリクルートです。リクルートは「ゼクシィ結婚トレンド調査」など、結婚・婚活に関する業界屈指のデータを毎年公表している会社でもあります。その会社が、なぜ自社の婚活アプリの成婚率を公表しないのか。

おそらく理由は、成婚率という指標が測定が難しいからです。アプリを通じて出会い、その後交際し、入籍する——このプロセスを追跡することはシステム的に困難ですし、ユーザーが退会した後の結末はアプリ側には把握できません。

ゼクシィ縁結びが公表していること・していないことを整理すると以下のようになります。

**公表していること**
- 「真剣交際」「成婚退会」に特化した婚活特化型のサービスであること
- 毎週のおすすめ機能があること
- 月額プランの料金体系

**公表していないこと**
- 成婚率・婚姻率
- 会員数・男女比
- 月間マッチング数

この情報の非対称性は、ゼクシィ縁結びに限らず業界全体の構造的な問題です。ユーザーとして賢く立ち回るには、「公表されている数字だけを根拠にする」というシンプルな原則を持つことが大切です。

婚活アプリ選びを検討中の方は、ぜひ公式発表データだけに基づいた比較を意識してみてください。

（NOEマッチングアプリ大学の記事では、各アプリが公表している数字と非公表の数字を一覧で整理しています。詳細はプロフィールのリンクからどうぞ。）
