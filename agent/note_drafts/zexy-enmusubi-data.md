# ゼクシィ縁結びの成婚率は「公表されていない」が正解——非公表を理解することの意味

婚活アプリを選ぶとき、「成婚率が高いサービスにしたい」と思って検索すると、さまざまな数字が出てきます。「〇〇%」と書かれた比較表、「業界最高水準」という見出し。でも実際のところ、「成婚率（%）」を公式サイトで正式に公表しているマッチングアプリは、ほとんど存在しません。

ゼクシィ縁結びも例外ではありません。リクルートが運営するこのサービスは、ゼクシィという結婚関連ブランドの認知度を持ちながら、「成婚率〇%」という数字は現時点で公表していません。累計会員数もアクティブ会員数も、公式サイトには明示されていない状況です。

「じゃあ、信頼できないサービスなの？」と思うかもしれませんが、そうではありません。問題なのは「非公表かどうか」ではなく、「ネット上に流通している試算値を成婚率として読んでしまうかどうか」です。

マッチングアプリで成婚率（%）を計算するには、分母となる「有効会員数（実際に使っているアクティブな会員の数）」が必要です。でもほとんどのサービスがこの数字を出していない。だから、累計登録者数を分母にして「成婚率〇%」と書いてある記事が多いのですが、これは実態とはかけ離れた計算になっています。「非公表な数字を使って計算した推測値」と、「公式発表された数字」は、まったく別物として扱う必要があります。

ゼクシィ縁結びが「公式に言っていないこと」を「言っている」ように紹介している情報は信頼できません。逆に言えば、「公表していない」という事実を正直に書いた情報の方が、判断材料として使えます。

「成婚率が分からないなら、何を基準に選べばいいの？」という疑問はもっともです。記事ではこの点も整理しています。会員の婚活意向の明示度、料金設計の方向性、プロフィール項目の充実度——これらは数字が出なくても確認できる材料です。実際に使った方の体験談も2名分紹介しています。
