# 共働きの「今日どうする？」、実は毎日いくら払っていますか

自炊は1食250〜450円で60〜90分。外食は1,000〜2,000円で調理も片づけもゼロ。
この2つの数字を並べた瞬間、共働きの食事は「安いか高いか」の話ではなくなります。

共働き夫婦の食事について、1食あたりの費用と所要時間を同じ表に並べて整理してみました。

自炊はたしかに最安です。ただし所要時間には、調理の30〜40分だけでなく、献立を決める5〜15分、買い物の20〜40分、片づけの10〜20分が含まれます。通しで60〜90分。これを平日5日続ければ週5〜7時間になります。

一方、ミールキットは1食600〜900円（各社公式サイトの公開価格帯より）。自炊より200〜400円高いのですが、消えるのは献立決めと買い物という、いちばん気力を使う工程です。惣菜は500〜800円で20〜35分。外食・デリバリーは1,000〜2,000円で、調理と片づけがゼロになります。

ここで大事なのが、ミールキットの使い方です。自炊の置き換えとして入れると支出は増えます。減るのは外食・デリバリーの置き換えとして使ったときだけ。「何を減らすために入れるのか」を先に決めていないと、結果が正反対になります。

外食も同じで、週1回から週3回に増えるだけで月の支出が2万円前後変わります。共働き世帯の食費が想定を超えるとき、原因は食材費ではなくほぼここです。しかも金額で制限するより、回数で決めた方が続きます。

そして記事を書きながらいちばん腑に落ちたのは、食事の分担で揉める原因が料理の腕ではないということでした。献立決め・買い物・調理・片づけは別の作業です。「作る人」だけを決めると、見えない工程が片側に寄る。時間で可視化すると、途端に話し合いやすくなります。

結論はシンプルで、方式を選ぶのではなく週の枠に割り当てて「その日に決めない」状態を作ること。これだけで費用と時間が同時に安定します。
