# 産後、妻が「別人」になるガルガル期。実は産前に測れます

出産を境に、妻がピリピリしはじめた。抱っこの仕方を注意される。義実家の訪問を嫌がる。何をしても唸られる——。

これ、世間で「ガルガル期」と呼ばれる状態です。名前はかわいいですが、渦中の夫婦にとっては笑いごとではありません。今日は、このガルガル期について「知っておくだけで景色が変わること」を整理します。

## ガルガル期は病気ではなく、防衛本能

ガルガル期は医学用語ではなく俗称です。中身は、ホルモンの急変動と「赤ちゃんを守る」本能によって、警戒心と攻撃性が一時的に高まる状態。我が子を守る動物の母親が「ガルルル」と唸る、あの状態が名前の由来です。

大事なのはここです。これは性格の欠陥でも、愛情の欠如でもなく、生き物として正常な反応だということ。哺乳類の母親が出産直後に防衛的になるのは、動物行動学では広く知られた話で、ヒトだけが例外ではありません。

「私はおかしくなってしまった」でも「妻が豹変した」でもなく、防衛システムが正常に作動しているだけ。まずこの認識を夫婦で共有できるかどうかで、その後の消耗がまるで違います。

## 「いつ終わる？」は、間違った問い

ガルガル期の期間は個人差が非常に大きく、数週間で抜ける人もいれば、1年近く続く人もいます。つまり「いつ終わるか」は誰にも分かりません。

ただ、実務的にはっきりしていることがあります。期間を決めるのは時計ではなく環境だということです。睡眠が確保できているか、夫が夜間対応を分担しているか、義実家との距離を調整できているか、頼れる先が実家以外にあるか。ここが整っている家庭は軽く短く済み、崩れている家庭は長引く。

だから正しい問いは「いつ終わる？」ではなく「何を整えれば短くなる？」です。

## 牙の鋭さは、産前に見積もれる

そしてここが本題です。ガルガル期がどれくらい強く出そうかは、気質・体質・家族背景・環境からある程度、産前に予測できます。

たとえば、睡眠不足で人格が変わるタイプか。PMSの変動幅は大きいか。実母は産後どうだったか。夫は夜、家にいられるか。こうした要素の掛け算で、牙の鋭さはかなり読めます。

うちの編集部では、この考え方を53問のチェックリストにした無料診断を作りました。結果は「ひだまりの猫」から「伝説のサーベルタイガー」までの4段階。パートナーの被害想定と、タイプ別のサバイバルガイド付きです。2分で終わる15問版もあります。

## 夫ができることは、実は3つだけ

対処法を細かく言えばキリがないのですが、効くのは結局この3つです。

・睡眠を「プレゼント」ではなく「シフト」にする。夜間対応を曜日で固定分担する
・「手伝おうか？」をやめて「担当する」。指示されなくても完結する持ち場を持つ
・唸られたら反論せず、補給する。怒りの原因の8割は睡眠・食事・ひとり時間の資源切れ

逆に一番まずいのは「そんなに怒らなくても」と正論で返すこと。火に燃料を足す行為です。

## これだけは覚えておいてほしいサイン

最後にひとつだけ真面目な話を。赤ちゃんが寝ていても眠れない、食べられない、赤ちゃんへの加害念慮、幻聴・幻覚。これらはガルガル期ではなく、産後うつ・産後精神病のサインの可能性があります。当てはまったら様子見をせず、産婦人科・自治体の産後ケア窓口へ。

ガルガル期は設計で乗り切れます。でも受診が必要な状態は、根性や愛情では乗り切れません。この区別だけは、夫婦で共有しておいてください。
