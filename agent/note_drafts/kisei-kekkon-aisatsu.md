# 新婚1年目の正月、頑張りすぎると「毎年の基準」になってしまう話

**タイトル案：** 義実家の正月、初年にフル滞在した夫婦が2年目に困る理由

婚約中〜新婚1年目の年末年始は、結婚生活で最初の「両家イベント集中期」です。帰省マナーの記事は世の中に多いのですが、実際に当事者を悩ませるのはマナーより「二つの実家の期待を、限られた休みでどう両立させるか」という調整問題の方です。

まず最大の論点、「どちらの実家を優先するか」に全国共通の正解はありません。実際に使われているのは、1年ごとに入れ替える「交互型」、年末と年始で分ける「分割型」、正月は一方で盆や連休はもう一方という「イベント分担型」の3類型。どれを選ぶにしても、成否を分けるのは「ふたりで相談して決めました」と夫婦を主語にして両家に伝えることです。

手土産の相場は2,000〜5,000円程度が一般的な目安。金額より効くのは「日持ちするか」「集まる人数で分けられるか」「相手の地元の銘菓と被っていないか」の3チェックです。お年玉は一般相場より親族内の相場が最優先なので、パートナー経由の事前確認が必須。ここを怠って包み直しになった、という失敗談は珍しくありません。

そして見落とされがちなのが、初年の頑張りすぎがそのまま毎年の期待値になるという構造です。初年に三が日フル滞在をやり切ると、翌年の短縮が「手抜き」に見えてしまう。最初から「1泊2日で失礼します」という型を丁寧に作り、夫婦だけの正月時間も予定に組み込んでおくのが、長く続く両家関係のコツです。

記事では、優先順位3類型の比較表、滞在マナー（手伝い・呼び方）、泊まりを打診された時の受け方・断り方まで整理しています。
