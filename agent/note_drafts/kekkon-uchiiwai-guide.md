# 結婚内祝い、「半返し」を守るとかえって失礼になる場面がある

**タイトル案：** 結婚祝いに10万円もらったら、5万円返しますか？

結婚内祝いを調べると、どのサイトにも同じことが書いてあります。「半返しが基本」「挙式後1ヶ月以内に」。原則としては合っているのですが、実際に手が止まるのはここではありません。止まるのは、原則から外れる場面です。

たとえば、親から10万円のお祝いをいただいたとき。半返しなら5万円ですが、これは相手の厚意を額面で打ち消してしまう形になりかねません。目上の方からの高額なお祝いは、支援の意味を含んでいることが多いためです。この場合は3分の1程度に抑え、そのぶん礼状を丁寧にするほうが自然だとされています。金額を正確に合わせることが目的ではないんですね。

職場から「一同」でいただいた場合も迷いやすいところです。総額3万円だと1万5,000円の品を選びたくなりますが、12人からの一同なら一人あたりは2,500円。返すべきは一人1,200円前後で、個包装のお菓子を人数分そろえるほうが実際には喜ばれます。1万5,000円の品を1つ職場に贈っても、誰も手をつけられないまま置かれることになりがちです。

意外な落とし穴として、のしの水引もあります。結婚は「一度きり」なので紅白10本の結び切りが正解で、蝶結びは使いません。ところがネット注文だと蝶結びが初期設定になっていることがあり、そのまま進んでしまう人がいます。

そして、遅れてしまった場合。「もう遅いから贈らない」が一番避けたい選択です。遅れたことより、返らなかったことのほうが関係に残ります。お詫びを一言添えて速やかに贈れば、指摘されることはほとんどありません。
