# 妊活サプリの広告、「事実」と「訴求」を分けて読むと景色が変わる

**タイトル案：** 男性妊活サプリの口コミ、効果を断定してる情報ほど怪しい理由

男性向け妊活サプリ「マイシード」について調べると、効果を語るブログ記事がたくさん出てきます。でも制度上の事実として、サプリは栄養補助食品なので「精子が増える」「妊娠できる」といった効果は標榜できません。つまり、効果を断定している情報ほど信頼できないという逆説が成り立ちます。

では何で判断すればいいのか。確認できる事実は3つです。

1つ目は成分。マイシードの場合、亜鉛・還元型コエンザイムQ10・ソイポリア（大豆由来ポリアミン）が主要成分として公式サイトに公表されています。「配合されている」という事実までが確認できる情報で、その先の効果は誰にも保証できません。

2つ目は価格と継続条件。定期コース中心の販売なので、初回価格ではなく「2回目以降の価格×継続予定月数」の総額で見積もる必要があります。解約の連絡期限や最低継続回数も申込み前の必須確認事項です。

3つ目は必要な期間。新しい精子がつくられるまでには約74日かかるとされていて、サプリは数ヶ月継続が前提の商品です。1〜2週間で判断できるものではない代わりに、数ヶ月分の予算を先に見積もる必要があります。

そしてそもそも、サプリの前に精液検査（数千円〜1万円台）で現状を知るのが先、というのが記事全体の結論です。

記事では、成分の事実と公式の訴求の区別、口コミの読み方、他サプリとの比較軸まで整理しています。
