# 結婚を機に転職する人が、入籍前後どちらを選んでいるか調べてみた

**タイトル案：** 結婚と転職、どっちを先にすべき？住宅ローンとの意外な関係

結婚を機に転職を考える人は多いですが、「入籍前」と「入籍後」どちらのタイミングがいいのか、実はあまり語られていません。

一番見落とされがちなのが住宅ローン審査との関係です。転職直後は勤続年数が短いとみなされ、審査が通りにくくなる傾向があります。新居を購入する計画があるなら、転職と住宅購入のタイミングをずらす必要が出てきます。

結婚を機に転職を考える理由は主に3つに集約されます。一つ目は労働時間・ワークライフバランス。夜勤や不規則勤務があると、相手との時間確保が難しくなります。二つ目は勤務地。転勤なし希望や、相手の勤務地に合わせた転職を考える人も多い。三つ目は世帯年収。家庭を持てる収入水準への引き上げを目的にするケースです。

どのタイミングにも一長一短があります。焦って決めるより、まず「なぜ転職したいのか」を明確にしてから動く方が、結果的に納得のいく選択になりやすいようです。

記事では、住宅ローンとの関係、転職理由別の判断基準、看護師や公務員などの具体例まで詳しく解説しています。
