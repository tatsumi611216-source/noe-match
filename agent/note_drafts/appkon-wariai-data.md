# 「アプリで出会った夫婦」は今どのくらいいるの？データで見る婚姻割合の実態

マッチングアプリで出会って結婚するカップル、実際どのくらいいるのかご存知ですか？「周りで増えてる気がするけど、全体でどのくらいの割合なんだろう」と気になっている方も多いと思います。

国立社会保障・人口問題研究所が5年ごとに行う「出生動向基本調査」（2021年実施）によると、インターネット・SNSを通じて出会ったカップルの割合は推計13〜14%程度にのぼります（「マッチングアプリ」の項目は民間調査ほど細分化されていないため、ネット経由全体の推計値）。2015年調査では同様の数値が数%程度だったことを考えると、わずか6年でここまで伸びた変化幅はかなり大きいといえます。

一方で、ブライダル総研などの民間調査では「マッチングアプリで出会った」と限定したカップルが20〜30%台に達するという報告もあります。調査対象・調査年・質問の切り方によって数値が変わるため、一概に「正解」の割合は言えませんが、「5人に1人〜7人に1人くらい」というイメージは持っておいてよさそうです。

特に注目なのが年代別の差です。20代〜30代前半に限ると、アプリ経由で出会った割合はさらに高くなる傾向があります。職場・学校・友人紹介といった従来のルートが細くなっている現代では、マッチングアプリはすでに「特殊な出会い方」ではなく「普通の選択肢のひとつ」になりつつあります。

また地域別でも差があり、地方ほどアプリへの依存度が高い傾向があります。都市部は出会いの場が多い分アプリ一択にはなりにくいですが、地方では「近所に出会いの場がない」という現実からアプリが有力な手段になっています。
