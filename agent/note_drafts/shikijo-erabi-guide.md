# 結婚式場の「初回見積もり」を信じてはいけない理由

**タイトル案：** 式場の初回見積もりから100万円上がるのは普通です。契約前に知っておきたいこと

結婚式場探しで多くの人が驚くのが、初回見学時の見積もりと最終的な支払額の差です。100万円前後上がるのは珍しくありません。

これは営業手法である以上に、実際に見比べれば差がわかるからです。初回見積もりは最低ランクの構成で作られていて、装花・料理・衣装・写真・映像のグレードを実際に選んでいくと、ほぼ全員が上のランクを選ぶことになります。「このグレードだと当日こう見えます」と実例を見せられれば、多くの人が上げる判断をしてしまう。

対策はシンプムです。①見積もりに「衣装2着・装花の中間ランク・写真と映像込み」の条件で再作成を依頼する、②持ち込み料の有無と金額を確認する、③「この見積もりから上がるとしたらどこですか」と直接聞く。誠実な会場ほど正直に答えてくれます。

もう一つ見落とせないのが、見学予約サイト経由で予約すると特典(商品券など)が付くことが多い点。同じ会場でも、どこから予約したかで数万円の差が出ることがあります。

見学は3〜4会場に絞るのが効率的です。5会場を超えると記憶が混ざって比較できなくなります。「第一候補」「タイプの違う会場」「予算を抑えた会場」の3方向で見るのがおすすめです。

記事では、式場探しのスケジュール、見学予約サイトの特典比較、契約前に確認すべき項目まで詳しくまとめています。
