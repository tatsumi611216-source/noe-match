# Pairsの「2,000万人」は今使っている人の数じゃない——累計と実稼働を区別して読む

「Pairsは2,000万人が使っているから安心」と聞いたことがあると思います。でも、この数字をそのまま信じると、使い始めてから「あれ、思ったより少ない？」と感じることになるかもしれません。

Pairsが公式に発表している「累計登録者数2,000万人超」（公式発表）は、サービスが始まってから現在まで、一度でもアカウントを作ったすべてのユーザーの合計です。退会済みの人、何年もログインしていない休眠ユーザー、引っ越しや状況変化でやめた人——そういった人たちも全員カウントされています。

今この瞬間、実際にサービスを使っている人の数（アクティブ会員数）は、非公表です。

これはPairsだけの話ではありません。ほとんどのマッチングアプリがアクティブ会員数を公表していないのは、公開するとアクティブ率（累計に対して実際に使っている人の割合）が計算されてしまい、競合に戦略情報を提供することになるからです。

だから「2,000万人の中から探せる」という感覚で使い始めると、実際に自分の条件（年齢・居住地・婚活目的）を絞ったときの表示人数が、想像より少ないことに気づきます。これはPairsが嘘をついているわけではなく、「累計」という数字の性質の問題です。

Pairsはさらに「毎月13,000人に恋人ができた」（公式発表）という数字も出していますが、これは「恋人関係が始まった」という自己申告データで、婚約・入籍（成婚）とは別の話です。婚活目的で成婚率の参考にしようとすると、ズレが生じます。

「2,000万人」の数字は嘘ではないし、会員規模の大きさは選択肢の広さには確かにつながります。ただ、「会員数が多い＝自分に合う相手が多い」ではない、という点は理解してから使う方がいいと思います。
