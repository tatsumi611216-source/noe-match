## note の役割（2026-08-15 CEO決定・A案）

**note はサイト記事と1対1で書かない。** 同じ話を両方に書くと共倒れになる。
note の役割は次の2つに限定する。

1. **ビッグワードを狙う** —— サイトでは大手が強すぎて勝てない語（「産後」「夫婦」
   「離婚」といった単体の大語）を、note のドメイン評価とプラットフォーム内流通で取りに行く
2. **ガルガルクラスタと収益記事をサポートする** —— 記事末尾から
   サイトの該当記事・ツールへ送客する。noteは入口、サイトが着地点

**書き分けの原則：note は体験談・語り口、サイトは整理された情報。**
同じ見出し構成をnoteに再掲しない（重複コンテンツとして両方が沈む）。

投稿先は **hachimitsu88812（Noe結婚設計室）**。giraffe777（仕組み設計室）には出さない。

### 入口ワードの選定（2026-08-15実測）

note の #タグ件数＝note内にその語でどれだけ書かれているかの実数。
**多すぎる語は埋もれ、少なすぎる語は読者がいない。中間帯（およそ500〜5,000）が狙い目。**

**避ける（過密）**：婚活134,768／家計管理47,632／育休45,545／結婚相談所35,775／
ワンオペ育児33,319／結婚式32,337／**産後22,288**

**避ける（薄い＝読者がいない）**：**ガルガル期247**／結婚費用48／二人目育児113

> **重要：noteで「ガルガル期」を正面から書いても届かない（247件）。**
> noteは中間帯の語で入り、**サイトのガルガル記事とツールへ送客する**。
> これがA案の正しい実装であって、サイト記事のnote版を書くことではない。

### ビッグワードの扱い（2026-08-15 CEO判断）

**大語単独狙いは現時点では採らない。** 理由は3つ。

1. note内で埋もれる（産後22,288本／婚活134,768本に対し、当アカウントは記事12本・フォロワー8）
2. Google側でも大語は大手医療・企業メディアが占有しており、note経由でも勝てない
3. 実測で、大語の手前ですでに「投稿数と反応が比例しない」ことが出ている

**採る形：主題は中間帯、タグでビッグワードを併記する。**
noteは1記事に複数タグを付けられるので、狙う語は排他ではない。

- **本文の主題**＝中間帯の語（上位表示を取りにいく）
- **タグ**＝主題の語 ＋ ビッグワード（#産後 #夫婦 等。大語の棚にも並べる）
- **本文中の語**＝ツール語（ガルガル期）を自然に含める（送客と指名検索の種）

**大語を正面から狙うのは条件が揃ってから**：中間帯で書いた記事のスキ中央値が
安定して20を超え、フォロワーが3桁に乗った段階。

### 文字数の目安（2026-08-16実測）

対象語の検索上位39本の**実本文**を取得して測った結果。

| | 中央値 |
|---|---|
| 義実家・スキ30以上（16本） | **1,425字** |
| 義実家・スキ30未満（4本） | 889字 |
| 夫婦仲・スキ30以上（7本） | **2,148字** |
| 夫婦仲・スキ30未満（12本） | 2,107字 |

**上位は1,000〜2,500字に収まる。**サイト記事の4,000字級はnoteには存在しない。

**ただし長さとスキに相関はない。**夫婦仲では上位も下位も中央値2,100字前後で差がゼロ
（スキ152で376字、スキ84で2,289字といった具合に長短が入り乱れる）。
**長さは効かない。効いているのは中身。**

→ **note は1,200〜1,800字を目安**にする。長く書くとサイト記事と食い合い、
noteで全部答えてしまうとクリックする理由が消える（noteは入口・サイトが着地点）。
短くするときに削るのは**網羅的な表や手順の列挙**（それはサイトの役割）。
残すのは**切り口と語り口**。
