# note 60本計画（2026-08-28 設計・1か月分）

## 0. 前提となる実測（この計画の根拠）

### noteドメインは「2週間で1位」を取る

公開済み12本の狙い語をSERPで実測した（2026-08-28・DDG）。

| 検索語 | うちのnoteの順位 | 公開からの日数 |
|---|---|---|
| 両家顔合わせ 揉めた | **1位** | 14日 |
| 長男 結婚 揉める | **1位** | 15日 |
| 婚活アプリ 総額 期間 | **1位** | 26日 |
| 40代 独身女性 婚活 厳しい | **2位** | 14日 |
| 嫁姑 こじれる 家 | **2位** | 10日 |
| 義実家 しんどい 心が狭い | **3位** | 12日 |
| 看護師 出会いがない | **5位** | 15日 |
| ガルガル期 産前／オタク婚活／ぽっちゃり婚活 | 圏外 | ― |

**10本中7本が1ページ目、うち3本が1位。**
noe-match.com は3ヶ月かけて1ページ目1語（8位）だったのに対し、
noteは**2週間で1〜3位**に入る。ドメインの差は決定的。

### 勝ち負けの分かれ目（実測から）

- **勝った型**: 感情・構造系（義実家／顔合わせ／長男／嫁姑）＋ 数字読み系（婚活アプリ総額）
  ＝「中間帯の悩み語 × 構造で説明する」
- **負けた型**: 属性ニッチ（ぽっちゃり・オタク）と、造語に近い語（ガルガル期 産前）
- 2020年の商品名レビュー（キレイモ等）は6年で1日0.1PV → **商品名単体は出さない**

### 役割分担（これがこの計画の骨格）

```
Google/Yahoo/Bing
   │  ← noteが2週間で1〜3位を取る（集客はnoteが担う）
   ▼
note記事（悩みの構造を語る・1,900〜2,500字）
   │  ← 記事内導線（器具1・関連記事1・LINE1）
   ▼
noe-match.com の器具（計算機・診断）← 収益CTA（アフィリ・LINE）はここにある
   │
   ▼
LINE登録 ／ アフィリ成約
```

**noteは集客装置、noe-matchは転換装置。** noteに広告は貼れない（規約）ので、
この分業以外に選択肢はない。noteのPVを追わず、**noe-matchへの送客数**をKPIにする。

### 記事内導線の型（全記事共通・3本固定）

1. **器具**（上のT1〜T6のどれか）… 本文の文脈で自然に。「計算できます」「測れます」
2. **関連記事**（noe-matchの詳細版）… 「詳しくはこちらに整理」
3. **LINE**（`https://lin.ee/unbDsCR`）… 末尾の定型ブロック「変わった点だけを月1回」

リンクは必ず `<a>` でタイトルをテキストに。素URL禁止。3本を超えて貼らない
（リンクだらけの記事はnote内で回遊されない）。

## 3. 運用ルール

- 予約は `localStorage.__go` のワーカーで1コマンド（手順は note_schedule.md）
- 週1回、公開済み記事の狙い語SERPを実測して勝敗表を更新（勝った型に寄せ続ける）
- **note→noe-matchのリンクは9月中旬の判定に影響する**（外部リンクが増える）。
  判定時は「note経由の流入」をGA4のreferrerで分離して読むこと
- noteのPVではなく、GA4の `sessionSource=note.com` を週次で見る
- 予約在庫は常に3日分以上キープ。切れそうなら制度クラスタから前倒し
