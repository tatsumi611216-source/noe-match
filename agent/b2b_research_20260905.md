## 1. 結論（3行）

- 買い手候補9業種内の実ページを見た限り、**全社が既に自前で「自治体の子育て支援比較」コンテンツを出している**（不動産7社中7社、保険/FP4社中4社、ベビー/保育5社中5社）。制作は「公的一次資料＋有資格者監修（相場2〜4万円/記事）」で完結しており、外部データを買っている形跡が実ページに出ているのは東急リバブル（アスコエ「ジモトク」導入企業として掲載）のみ。
- 無料代替は強い。東京都の「子育て支援制度レジストリ」は60区市町村＋都・約7,260制度を CC BY 4.0 で公開し、**金銭的支援額・対象年齢・利用費用が構造化列**で入っている。ただし**2025-08-20 で更新終了**（国のレジストリへ移行、国側は API 利用申請＋審査制）。所得制限の列は無く、保育指数・結婚新生活支援は対象外。
- 判定は **条件付き需要あり**。売れるのは「制度の存在」ではなく「**月次で検算した鮮度と差分**」と「**所得制限・自己負担まで含む粒度**」。単価の目安はデータAPIで月額10〜30万円（他分野の実例）、監修で2〜4万円/記事。実額ベンチマークは子育て分野では取れなかった。

## 4. 判断に効く所見

1. **「比較コンテンツを持っていない企業」は見つからなかった。** 17媒体すべてが既に出している。制作原価は「公的一次資料の転記＋有資格者監修2〜4万円」で、これが実質の競合価格。データを売るなら「記事1本分より安いか、記事では作れない何か」でないと成立しない。
2. **鮮度が共通の穴。** 東急リバブル town/11695 は3年、キッズラインは1年半、ポピンズは更新日なし。アスコエ（ジモトク）ですら年2回更新。noe-match は月次再確認（CHECKED=2026-08-29）なので、売り物は「データ」より「**差分通知**」（今月変わった区・制度・金額）である可能性が高い（仮説）。
3. **無料レジストリは「凍結」した。** 都版は2025-08-20で更新終了、国版は申請・審査制。2026年9月時点で「誰でも落とせる最新の構造化データ」は存在しない。この空白は国版が公開XLSを出すまで続く（期間は未取得）。
4. **レジストリに無い列がバンクの差別化点。** 所得制限額・課税/非課税別の自己負担・月額上限（`_hitorioya_data.py` の `shotoku_seigen`/`futan` に相当）は自由記述にしか無い。保育指数・結婚新生活支援はそもそも対象外。
5. **既にデータを買っている買い手が存在する**（ジモトク導入: 東急リバブル・第一生命・阪急阪神不動産・NTTドコモ・NTTデータ）。価格は非公開だが、「大手は買う」という事実は取れた。逆に地場（アドキャスト・スムトコ・イー・トラスト）はCFP/宅建の社内人材で自作しており、買う習慣が見えない。
6. **一都三県限定は、全国1,700自治体を持つジモトク／生活ガイドと同じ土俵では負ける。** 勝てるのは「東京で深い」用途（区単位の提案書・店舗ページ・LINE配信）に限られる（仮説）。
7. **他分野の実額**（スマエネ補助金API 月額10〜30万円・Excel月額50万円）は、法人向け自治体データが月額二桁万円で成立している証拠。子育て分野で同水準かは未取得。

## 6. 判定と、次にヒアリングする3社の順番

**判定: 条件付き需要あり。**
条件は「制度の存在を売らない」こと。売るのは (a) 月次の**差分レポート**、(b) 所得制限・自己負担まで入った**粒度**、(c) 区を選ぶ**器具の埋め込み**の3点。価格帯の仮説は「監修1本（2〜4万円）を下回る月額」から「データAPI（10万円/月〜）」の間。

ヒアリング順（連絡は事業部長/CEO判断。ここでは順番と理由のみ）:
