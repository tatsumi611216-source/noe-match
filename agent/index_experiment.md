## 目的：未解明の1点を切り分ける

URL Inspection API の実測（146URL）で、**無修飾ヘッドターム17本のインデックス率だけが
0.0%** だった。同じコホートAの平均24.1%を大きく下回るので、公開時期では説明できない。
考えられるのは2つで、**打ち手が正反対になる**。

| 仮説 | 意味 | 正しければやること |
|------|------|------------------|
| (i) クロール順が後回しなだけ | Googleは価値判断をしていない。単に手が回っていない | 待つ／申請する。記事はそのままでよい |
| (ii) Googleが価値なしと判断している | 見た上で載せていない | 記事の中身か主題を変えるしかない。申請しても無駄 |

**GSCの「インデックス登録をリクエスト」を使えば、この2つを分離できる。**
申請して入るなら (i)、申請しても入らないなら (ii)。

## 注意

- **申請は「順位を上げる操作」ではない。**クロールの順番を早めるだけで、
  入った後に表示が立つかは別の問題（インデックス済み47本のうち表示があるのは25本＝53%）
- **申請しても必ず入るとは限らない。**Googleが載せないと判断していれば変わらない。

- 実験中は**新記事の公開ペースを週2本のまま変えない**。変えると何が効いたか分からなくなる
