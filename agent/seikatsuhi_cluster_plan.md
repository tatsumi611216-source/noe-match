### なぜ「分担」まで出すのか（サジェスト実測）

需要は金額より**分けかたの悩み**に集中している。

- `夫婦 生活費 負担割合` `夫婦 生活費 負担割合 収入差 計算`
- `夫婦 生活費 折半 おかしい` `夫婦 生活費 いくらずつ`
- `同棲 生活費 割合` `同棲 生活費 収入差`
- **`シュミレーション` が3系統に出現**（新婚 生活費／二人暮らし 生活費／二人暮らし 初期費用）
  ＝**ツールそのものが検索されている**

大手の家計メディアは「平均額」までしか出さない。
**「あなたたちの収入比だといくらずつか」を出すツールは空白。**

### 入力・出力の設計

**入力**
- 住まい：地域（三大都市圏／地方都市／その他）・家賃・間取り
- 世帯：共働き／片働き、収入（2人分・手取り月額）
- 生活：食事スタイル（自炊中心／中食・外食多め）、車の有無

**出力**
1. **月額の内訳**（家賃・光熱・通信・食費・保険・日用品・その他）
2. **年額と、手取りに対する割合**
3. **分担の3案** —— 折半／収入比／定額＋残り収入比。それぞれ「いくらずつ」
4. **削れる余地**（固定費の見直し余地を金額で提示）

### 前提数値の出どころ（既存記事と揃える。矛盾させない）

サイト内で既に公表している数値を使う。ツールだけ別の数字を出すと事故になる。

| 費目 | 根拠（サイト内既出） |
|---|---|
| 食費 | 総務省「家計調査」二人以上世帯の食料支出 月7万円台〜9万円前後／二人暮らし共働きは**月5〜8万円**（`tomobataraki-shokuji-data`） |
| 通信（ネット） | 総務省「家計消費状況調査」2025年1〜3月期・二人以上世帯のインターネット代**月4,447円**（`futari-sumaho-minaoshi`） |
| 賃貸初期費用 | 家賃の**4〜6か月分**（`shinkon-seikatsu-guide`）／同棲は4〜5倍（`dousei-hajimekata`） |
| 家具・家電 | **30〜70万円**（`shinkon-seikatsu-guide`）／同棲は20〜40万円 |
| 引越し | **8〜30万円**（繁忙期は最大55万円） |

**光熱費・日用品・保険はサイト内に数値がないため、公的統計から取り直して
記事側にも同時に載せる**（ツールだけが数値を持つ状態を作らない）。


## ガルガルクラスタとの関係（2026-08-16 CEO確認）

**原則：接続しない。**

読者の段階が違う。新婚生活＝結婚直後・子どもなし（毎月いくら／どう分ける）。
ガルガル＝産後・子どもあり（この状態は何か／どう乗り切るか）。
時間軸では連続するが**同時に読む読者はいない**。無理に相互リンクすると
双方のトピックの焦点がぼやけ、クラスタを分ける意味がなくなる。

**例外は2本だけ。生活費側から参照する（片方向）。**

| 記事 | 理由 |
|---|---|
| `ikukyu-fuufu-doji` | 中身が**収入の谷＝家計の話**。産後の記事だが生活費の読者にも実用的 |
| `kekkon-hiyou-futan` | **分担の考え方（同じ額か、同じ痛みか）が両クラスタ共通**。ツールの分担3案と思想が同じ |

**繋がないもの**：ガルガル診断／産後クライシス／義実家／夫婦仲／嫁姑。
回収クラスタに集客装置の記事を混ぜると、読者の目的がずれる。
