結婚相談所を調べていて、いちばん困るのがこれだと思います。

どこにも「結局いくらかかるのか」が書いていない。

入会金はいくら、月会費はいくら、お見合い料はいくら。項目はきれいに並んでいる。なのに、1年通ったら合計で何円になるのかが、どの公式サイトにも出てこない。

10社の公式料金ページを1つずつ開いて確かめました。1年間の総額を自社で公表していたのは、10社中2社だけでした。

残り8社は、足し算をこちらに任せています。だから比較サイトも項目別の表しか作れない。読者はいつまでも総額にたどり着けません。

足してみたら、7倍ひらいた

12か月活動して、成婚して退会した場合。各社が公表している入会金・初期費用・月会費・成婚料を、同じ条件で積みました。

- いちばん安い　125,400円

- いちばん高い　891,000円

7.1倍です。同じ「結婚相談所」という看板で、これだけ違います。

ここで多くの人が引っかかるのが、次の勘違いです。

月会費が安い相談所が、いちばん安いわけではない

総額の順番と、月会費の順番は一致しません。

試しに、同じ10社を成婚料を含めずに積み直すと、開きは7.1倍から4.5倍まで縮みます。

つまり差の大半は、月々の料金表には載っていない場所にありました。

成婚料です。

0円の社と、330,000円の社があります。そして成婚料は、成婚したときにしか発生しません。だから月々の料金を見比べているあいだ、この数字は一度も目に入りません。

婚活を始めるとき、人は「毎月いくら払えるか」で選びます。でも実際に効いてくるのは、うまくいったときに一度だけ請求される金額のほうでした。

「成婚料0円」には但し書きがある

では成婚料0円の社を選べばいいのかというと、そう単純でもありませんでした。

成婚料が0円と書かれている社のうち、2社は条件付きです。

ある社は「同じ相談所の会員同士で成婚した場合は0円」。ただし連盟（IBJ）の会員と成婚した場合は220,000円かかります。もう1社も同じ構造でした。

連盟の登録会員数は10万人規模です。つまり相手が連盟の会員である可能性は十分にあります。「成婚料0円」という見出しだけを見て予算を組むと、22万円ぶん外します。

「お見合い料なし」と「お見合い料の項目がない」は別物

もうひとつ、比較表がいちばん雑になるところがあります。

「お見合い料は0円です」と明記している社があります。一方で、料金表にお見合い料という項目そのものが無い社が5社ありました。

この5社を「無料」として表に載せると、実際にはお見合いのたびに費用が発生していた場合、読者が損をします。無料と書かれているわけではないからです。

なので今回作った試算ツールでは、項目が無い社を0円として扱っていません。回数を増やしても総額が動かないようにしてあります。無料カウンセリングで必ず聞くべき項目として残す、という扱いです。

数字が合っているかを、自分で検算した

金額を手で書き写している以上、取り違えたら記事ごと嘘になります。

なので、自社で1年間の総額を公表している2社を検算に使いました。

- ツヴァイ　118,800円 ＋ 15,950円×12 ＝ 310,200円

- スマリッジ　6,600円 ＋ 9,900円×12 ＝ 125,400円

どちらも公式サイトの公表値とぴったり一致しました。同じ積み方をしている他の8社の数字も、この2本が通ることで確かめられます。計算が合わなければ記事を生成しない仕組みにしてあります。

調べていて気づいた、細かいけれど重要なこと

コースが複数ある社は「どのコースか」で大きく変わります。 ある社は3コースで入会金が148,500円から451,000円まで開いていました。「◯◯は△△円」と書いている比較記事があったら、どのコースの数字かを確かめてください。

税込か税別かが揃っていません。 ほとんどの社は税込表記ですが、料金ページに税込・税別の明示が無い社もありました。ある社では初期費用には税込の明記があるのに、月会費のほうには見当たりません。

料金がページを開いただけでは出てこない社もありました。 金額がスクロールに連動して後から描画される作りで、サーバーが返す元のデータには数字が一切入っていません。自動で情報を集めている比較サイトの数字がずれることがあるのは、こうした構造も一因だと思います。

自分の条件で積み直せます

活動する月数、お見合いの回数、成婚するかどうか、相手が連盟会員かどうか。この4つを入れると、10社の総額を同じ条件で積んで安い順に並べるツールを作りました。

内訳が色分けされたバーで出るので、自分の場合はどこにお金がかかるのかが見えます。

最後に

金額の大小そのものより、「総額を出していない」という事実のほうが情報だと思っています。

10社中8社が出していない。出している2社は、どちらも比較的安い側でした。出せる社は出す、という単純な話なのかもしれません。

契約の前に、その社が総額を公表しているかどうかを見てください。していなければ、自分で足すか、聞くかです。聞いたときに即答できるかどうかも、たぶん情報になります。
