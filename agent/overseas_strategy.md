# 海外アフィリエイト戦略（2026-08-22 制定）

**現時点の結論：凍結。ただし廃案ではない。解禁条件を数値で定義する。**

運営者の意思決定（2026-08-22）：「日本がうまくいったら海外アフィをやりたい」。
本ファイルは、その「うまくいったら」を測定可能な条件に落とし、
条件を満たすまで工数を1分も使わないことを担保するために置く。

---

## 1. 「海外」を3つに分解する（この分解を飛ばすと必ず議論が濁る）

| 型 | 内容 | 判定 |
|---|---|---|
| **(a) 越境型** | 海外在住の読者を、その国の言語で、海外テーマで狙う | **恒久的に却下** |
| **(b) 吸収型** | 日本語のまま、海外テーマ（国際結婚・海外挙式・海外移住）を結婚軸に吸収する | **いつでも可**（軸展開モデルの範囲内） |
| **(c) 内なる海外型** | 日本在住の外国人（412万人）を英語等で狙う | **凍結**。下記の解禁条件つき |

### (a) を恒久的に却下する理由

noe-match が持つ資産は3つ——① 日本のアプリに関する事実、② 日本のASPの提携182件、
③ 婚活の一次体験。**越境型はこの3つすべてを捨てる。**
加えて、記事メディアが海外ASPで現実に取れるのは SOI $2-8／CPL $1-6 帯（約300〜1,200円）で、
日本のASP相場（2,000〜5,000円）を下回る。**言語を変えて単価が下がる施策に合理性は無い。**

> 注意：tier1 dating の CPA $40〜100 という数字が業界メディアに出回っているが、
> これは CrakRevenue / MaxBounty 等の**ペイドトラフィック前提**の数字である。
> SEO記事メディアの期待値として使ってはならない。

### (c) だけが検討に値する理由

読者の**居住国を日本に固定したまま、国籍だけを変える**と、上記の資産3つが全て生き残る。
日本のアプリの事実はそのまま使え、日本の案件にそのまま送れ、婚活の一次体験もそのまま効く。
変わるのは言語だけであり、**新クラスタを増やさない**ため
`strategy_2026H2.md` が敗因と断じた「15クラスタ分散」の再演にならない。

**狙う「国」は日本。狙う「国籍」は英語をハブに中国・ベトナム・韓国・フィリピン・ネパール。**
第2言語（ベトナム語）は、英語で表示が立つまで着手しない。

## 2. 市場の裏取り（2026-08-22 時点）

| 数値 | 実績値 | 出典 |
|---|---|---|
| 在留外国人数 | **4,125,395人**（2025年末・初の400万人超・4年連続過去最多）。中国・ベトナム・韓国で過半 | 出入国在留管理庁 |
| 国際結婚 | **年約2万件・全婚姻の約3.5%**。2006年の4.5万件・6.1%がピークで、そこから半減 | 厚労省 人口動態統計／内閣府 |

## 2-B. 「海外アフィそのものに可能性はあるか」（2026-08-22 調査）

noe-match の事情を切り離して、市場としての可能性だけを検証した結果。
**結論：可能性はある。ただし「英語で記事を書いてSEOで稼ぐ」形だけが、いま最も縮んでいる。**

### 層1：市場としては拡大中（○）

| 指標 | 数値 |
|---|---|
| 世界のアフィリエイト市場 | 2026年 約200億ドル → 2035年 826億ドル（CAGR 15.2%） |
| 米国単体 | 2026年 138億ドル → 2028年 約160億ドル |
| （比較）日本のマッチングアプリ市場 | 1,094億円 ≒ 7億ドル |

米国単体で日本の全マッチングアプリ市場の**約20倍**。「海外に金がある」は事実。

### 層2：記事SEOという経路は構造的逆風（×）

市場は伸びているのに、**記事アフィリエイトの取り分だけが縮んでいる。**

| 指標 | 数値 |
|---|---|
| AI Overviews出現時の上位ページCTR低下 | **−58%**（2025年4月の−34.5%から約2倍に悪化） |
| 2026年3月コアアップデートで順位を落としたアフィリエイトサイト | **71%** |
| **小規模パブリッシャー**（日次1,000〜10,000PV）の検索流入 | **−60%** |
| 中規模 −47% ／ 大規模 −22% | 小さいサイトほど削られている |
| ゼロクリック検索 | 約60% |
| Wirecutter の検索可視性（2025年5〜8月） | **−60%** |

損失は**情報型・エバーグリーン記事に集中**している。これはアフィリエイト記事の型そのもの。

### 層3：伸びているのは creator / 動画（△）

金は消えたのではなく移動した。ソーシャル系アフィリエイト **+46%**、
動画が全アフィリエイト流入の **55%** を占める見込み、TikTok Shop **年+48%**。
**伸びているのは「英語で顔を出して喋る人」であって「英語で記事を書く人」ではない。**

### 日本人固有のハンデ（3つとも実在）

1. **日本のASP案件は海外読者に売れない**（noe-match実測：提携182件中0件）
2. **AI翻訳記事では上位表示が取れない**（複数の実践者が明言）
3. **海外ASPは単価が低い**（SOI $2-8／CPL $1-6＝300〜1,200円 < 日本の2,000〜5,000円）

### それでも残る唯一の勝ち筋

**「日本のことを、英語で書く」。** 理由は3つとも構造的：

- 英語ネイティブの競合が**日本の事実を持っていない**（競合が薄い唯一の交差点）
- **一次情報・実体験はAI Overviewsが最も奪いにくい**（削られているのは情報型であって体験型ではない）
- **送り先を日本のASPにできる**＝海外ASPの安い単価を回避できる唯一の型

**逆に、「日本のこと」以外で英語圏に出るのは、2026年の数字を見る限り推奨しない。**
これは本ファイル冒頭の「(a) 越境型を恒久的に却下」を、市場データ側から追認する結果になった。

### 信頼度：B

市場規模とAI Overviews影響の数字は複数ソースで一致しているが、**出所の多くが業界メディアで一次ソースではない。**
−58%のCTR低下のみ反トラスト訴訟の提出資料分析が根拠で比較的強い。
「日本のASP相場2,000〜5,000円」も一次ソース無し（`asp_results.md` に管理画面の実単価を転記すれば解消できる）。

## 3. 着手を止めている本当の理由（2026-08-22 実測）

SEOでも言語でもない。**出口の案件がゼロだから**である。

提携182件（`AGENT.md` 台帳73件＋`program_queue.md` 未使用109件）を全文検索した結果：

| 検索語 | 未使用109件 | 台帳73件 |
|---|---|---|
| ビザ / 在留 / 行政書士 | 0 | 0 |
| 国際結婚 / 外国人 | 0 | 0 |
| 送金 / Wise / 為替 | 0 | 0 |
| SIM / eSIM / 格安スマホ | 0 | 0 ※ |
| 日本語 / 語学 / 英会話 / 翻訳 / 留学 | 0 | 0 |

※ grep のヒット1件は `kazoku-simhikaku`（**記事スラッグ**）であり、案件名ではない。

隣接カテゴリも確認済み：「起業・会社設立」2件はファクタリング、
「金融」は債務整理・不動産担保ローン・FP相談。**外国人向け導線に使えるものは1件も無い。**

主力4アプリ（Pairs / tapple / with / Omiai）に案件が無いのと**同じ壁が、英語側にもそのまま立っている。**
英語で1位を取っても送り先が無い。**記事を書いても解決しない。**

## 4. 解禁条件（AND条件。1つでも欠けたら着手しない）

### ゲートA：日本語で事業が成立していること

| # | 条件 | 2026-08-22 実測 | 意味 |
|---|---|---|---|
| A-1 | **確定報酬が累計3件以上** | **0件・0円** | 1件はまぐれ。3件で初めて再現性を疑える |
| A-2 | **月間オーガニッククリック 300以上** | 33（28日） | 現状の約10倍。母数が無いと英語の当たり外れも測れない |
| A-3 | **サイレント率 20%以下** | **50.8%** | 在庫が半分死んでいる状態で新規仕入れをしない |
| A-4 | **10位以内のクエリ 20件以上** | 2件 | 日本語で勝てていないものが英語で勝てる道理は無い |

### ゲートB：出口の案件が実在すること

| # | 条件 | 2026-08-22 実測 |
|---|---|---|
| B-1 | 配偶者ビザ・行政書士／国際送金／eSIM／オンライン日本語 のいずれかで**提携が1件以上成立** | **0件** |

**ゲートA全項目 AND ゲートB を満たした月に、初めて第一手を打つ。**
どちらか片方だけでは着手しない。特に **B だけ満たしても A が未達なら着手しない**
（案件が取れたことは、日本語で成立していない事実を何も変えないため）。

## 5. 解禁されたときに打つ第一手（先に決めておく）

条件を満たした後で設計を考え始めると、勢いで規模が膨らむ。**先に上限を固定しておく。**

- **`/en/` に3本のみ。** 4本目は60日後の判定を通るまで書かない
  1. `Dating apps in Japan for foreigners`
  2. `Can I use Pairs as a foreigner?`（指名×属性修飾。最も競合が薄い型）
  3. `Japanese spouse visa: what changes after you marry`（収益地点）
- **インデックス申請枠を1つも使わない。** 日本語記事からの内部リンクのみでクロールさせる
  （申請なし1.7%／申請あり90〜100%という実測がある以上、申請枠はサイト最大の希少資源。
  note経由の外部リンクで1.7%→20%になった実測があるため、リンク経路は申請の代替になり得る。
  この設計なら「英語需要があるか」と「リンク経由でインデックスされるか」を1つの実験で同時に測れる）
- **新規取材ゼロ。** 事実は既存の日本語記事から流用する
- **FTC準拠の表記**（"Advertisement" / "Ad"）を実装する。日本の「PR」表記では英語ページの要件を満たさない
- **撤退基準：60日後にGSC表示がゼロなら畳む。** 判定は `agent/kpi_history.json` の更新時に行う

### 解禁後もやらないこと

海外ASPへの登録／米英読者向けdatingコンテンツ／185本の翻訳（＝英語版サイト）／
ベトナム語・繁体字（英語で表示が立つまで）／新規ドメイン。
