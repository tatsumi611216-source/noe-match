# 「もっと挑戦しろ」と言われて挑戦しない会社員は、正しい

**タイトル案：** 稼ぐとは、ミスをすることである

会社員に「もっと挑戦しろ」と言う人がいます。言われた側は挑戦しない。それを性格の問題、気概の問題だと片づける人がいます。

違います。**構造に対して、完全に正しい行動をとっているだけです。**

## 報酬のグラフの形を見る

労働者の報酬は、下限が守られ、上限が閉じています。

会社が潰れないかぎり、来月も同じ額が入る。でも、どれだけ上振れさせても給料は上がりません。せいぜい賞与が少し動く程度です。一方で下振れさせれば、評価が落ち、責任を問われ、最悪は職を失う。

上に振れても得がなく、下に振れると損しかない。

この形に置かれた人間の最適戦略は、ひとつしかありません。ブレをゼロにすること。つまり、**ミスをしないこと**です。

## 資本の側は、形が逆になっている

事業者と資本家の報酬は、非対称の向きが反対です。

下限は投じた分で止まる。それ以上は失いません。だが上限は閉じていない。当たれば、投じた額の何十倍にもなる。

下に振れても限度があり、上に振れると青天井。

この形に置かれた人間の最適戦略も、ひとつしかありません。試行回数を増やすこと。つまり、**ミスをすること**です。

同じ人間が、置かれる場所によって正反対の最適解を持つ。能力の話ではなく、グラフの形の話です。

## だから、行動だけを変えろというのは無理な要求

「構造は変えないまま、行動だけ変えろ」というのは、成立しません。

報酬グラフが下向きの非対称のままで挑戦すれば、その人は損をするだけです。挑戦しないほうが合理的である状態に置かれたまま、精神論で押しても何も起きません。

行動を変えたければ、報酬構造の側に移るしかない。

## 一枚の表にすると、全部が同じ軸に乗る

| | 労働者の側 | 資本の側 |
|---|---|---|
| ブレの扱い | 出さない | 引き受ける |
| 報酬の非対称 | 下向き | 上向き |
| 最適な行動 | ミスをしない | 試行する |
| 評価のされ方 | 減点法 | 期待値 |
| 呼ばれ方 | 「仕事ができる」 | 「稼いでいる」 |
| 時間との関係 | 時間を売る | 時間から離れる |
| AIの影響 | 代替される | 増幅される |

左の列を極めても、右の列には一段も近づきません。同じ軸の、反対端だからです。

私は十五年、左の列を磨いて、右の列の結果が出ないことに首をかしげていました。

## 軸の名前は、不確実性

この表を貫いている軸には、名前があります。

**不確実性を消しにいく者が評価され、不確実性を引き受ける者が稼ぐ。**

そして、ここが面白いところです。金が「解決」ではなく「期待」に払われるのは、結果が不確実だからでした。結果が確定しているなら、期待という商品は成立しない。誰も未来に金を払いません。

つまり、こうなります。

**不確実性は、事業にとってコストではない。商品の原材料である。**

労働者は、確定を売って安全を買う。事業者は、不確定を買って上限を外す。どちらが偉いという話ではありません。ただし、両方を同時にやることはできない、という事実だけは動きません。

## 移るには、順番がある

では明日から資本の側に立てるかというと、立てません。順番があります。

資本の側の非対称は、元本があってはじめて機能します。元本ゼロで上限だけ外そうとすると、必ずレバレッジに手を出すことになる。そして下振れを引き受ける訓練をしていない人間に、レバレッジは扱えません。

だから順路は一つに定まります。**事業で元本をつくり、それを資本に移す。**

事業は、四つの稼ぎ方のなかで唯一、元本がほぼ要らないのに天井がない入り口です。代わりに下振れします。その下振れが、そのまま訓練になる。

そして資本が生活費を賄いはじめた瞬間、事業の意思決定から恐怖が抜けます。恐怖が抜けた事業は、当たる確率が上がる。稼ぐことが試行することである以上、恐怖は最大のコストだからです。
