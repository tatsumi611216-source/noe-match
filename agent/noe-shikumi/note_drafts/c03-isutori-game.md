# 「仕事ができる」は、椅子取りゲームの技能でした

**タイトル案：** 優秀な会社員が独立して詰む理由は、能力不足ではない

「あいつは仕事ができる」と言われる人の要件を、思いつくかぎり並べてみます。

段取りが組める。報連相が的確。ミスをしない。説明がうまい。気が利く。前例を知っている。誰に話を通せばいいか分かっている。

どれも立派な能力です。私も長いあいだ、この方向で評価されてきました。でも、並べてみると共通点がひとつあります。

**すべて、仕事がすでに存在していることを前提にしている。**

## 「仕事ができる」と「仕事を作る」は別物

「仕事ができる」とは、与えられた問題を誤差なく処理する技能です。問題は誰かがすでに設定してくれている。正解の形もだいたい決まっている。求められているのは、そこからブレないこと。

「仕事を作る」とは、誰も問題だと思っていないものを問題として立て、値段をつけることです。正解の形は誰も知らない。設定した本人すら知りません。

この二つを、日本語は同じ「仕事」という単語で呼びます。だから多くの人が、前者を極めれば後者に届くと思ってしまう。

届きません。方向が違うのではなく、**逆を向いています。**

## 椅子の数は、自分では増やせない

段取りも報連相も立ち回りも、組織という枠がなければ意味を持ちません。枠のなかで、限られたポジションを誰が取るかを競う技能です。だから椅子取りゲームと呼んでいます。

そして椅子取りゲームには、決定的な特徴があります。

**椅子の数は、自分では増やせない。**組織が決めます。だから上達しても、報酬は組織の都合で頭打ちになる。しかも、枠が消えた瞬間に値段がゼロになる。

## 稼ぐことの実務は、外すこと

では金を稼ぐ側の実務は何か。

何が解決策になるのか、事前には分かりません。分かるものなら、とっくに誰かがやっています。分からないから試す。試せば外れる。外れたら直してまた試す。

**外れることが業務内容なのです。**失敗ではなく、工程です。

「仕事ができる」＝ブレを小さくする技能。「金を稼ぐ」＝ブレを引き受けて期待値を取りにいく技能。最適化している対象そのものが違う。同じ「優秀さ」という言葉で両方を呼ぶから、話が混ざります。

## いちばん残酷な帰結

**「仕事ができる」訓練を十年積むと、試行できない人間ができあがります。**

ミスをしないことに最適化された神経系は、不確実な状態そのものに耐えられなくなる。結果が読めない案件を避ける。準備が整うまで出さない。完成していないものを人に見せられない。

全部、優秀な会社員としては正しい振る舞いです。そして全部、稼ぐ側では致命傷になります。

優秀な会社員が独立して詰むのは、能力が足りないからではありません。逆方向に鍛えすぎたからです。能力を足すのではなく、一度、鍛え方の向きを変える必要があります。

## 例外は、営業だけ

組織のなかで唯一、営業だけが「断られること」を前提に設計されている職種です。百件回って三件取れれば良い、という数え方を最初から仕込まれる。

つまり営業は、組織にいながら試行と失敗の訓練を受け続けています。営業出身者が独立に強い理由はここにあり、管理部門出身者が弱い理由もまったく同じ場所にあります。

私は後者でした。

## では、向きをどう変えるか

能力を足す発想をやめることです。

管理部門出身の私が最初にやったのは、資格を足すことでした。簿記、会計、法務。全部、解ける問題の難易度を上げる方向の努力です。向きは変わっていません。

向きを変えるというのは、具体的にはこういうことでした。

**完成していないものを、人に見せる。**結果が読めないものを、期限を切って外に出す。外れた記録を消さずに残す。

どれも会社員としては減点行動です。だから抵抗があります。私は最初、下書きを出すのに二週間迷いました。二週間迷ったこと自体が、鍛え方の向きの証拠でした。

一度でも「外して、死ななかった」経験を作ると、次から速くなります。訓練で作られた神経系は、訓練でしか変わりません。
