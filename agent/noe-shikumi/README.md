# Noe仕組み設計室 — 金軸チャンネル資産（2026-07-30 制定）

このディレクトリは **noe-match.com（婚活軸）とは別チャンネル**の資産置き場である。
noe-match の記事工場（`agent/AGENT.md`）はこのディレクトリを一切参照しない。

## なぜ noe-match.com に入れないのか

- AGENT.md の守備範囲規定：「恋愛・結婚と無関係のジャンル（転職・通信・金融単体など）の記事は生成しない」
- 金稼ぎの教科書は婚活文脈に接続できない純粋な金軸コンテンツであり、
  同一ドメインに置くと noe-match の専門性（E-E-A-T）を薄める
- 婚活SERPから来た読者にとって文脈が断絶する

したがって **sitemap.xml / sitemap-all.xml / index.html の記事一覧には絶対に追加しない。**
GitHub Pages の性質上ファイル自体は配信され得るが、内部リンクもサイトマップ登録もないため
実質的に非公開である。正式公開は別ドメインで行う（下記）。

## 母艦の公開手順

`textbook/index.html` には canonical / og:url / og:image / JSON-LD の4箇所に
`__ORIGIN__` というプレースホルダが入っている（計8箇所）。ドメイン確定後に一括置換する。

```sh
sed -i 's|__ORIGIN__|https://example.com|g' agent/noe-shikumi/textbook/index.html
```

置換後、`textbook/` の中身をそのまま公開先の docroot に置けば動く。
外部依存は Google Fonts のみ。ビルド不要・JSなし（進捗バーと目次ボタンのみ）。

### 公開先の選択肢

| 案 | 費用 | 備考 |
|---|---|---|
| 新規ドメイン＋GitHub Pages / Cloudflare Pages | 年1,000〜2,000円 | **推奨**。名前に紐づく資産になる。将来この軸を伸ばす場合の受け皿にもなる |
| note に全文掲載（母艦をnoteに置く） | 0円 | 最速。ただしドメイン資産が残らず、noteの体裁に縛られる |
| noe-match.com 配下に noindex で設置 | 0円 | 非推奨。婚活軸を薄める。テスト表示用の一時措置としてのみ可 |

### 下書きの書式ルール

- 実文字数 1,550〜1,800字・H2×5〜7
- 冒頭は具体例か断定から入る。定義から入らない
- 末尾は読者への問い（教科書のCHECKから1問）＋母艦へのリンク
- 各下書きの `{{TEXTBOOK_URL}}` は、母艦公開後に一括置換する

```sh
sed -i 's|{{TEXTBOOK_URL}}|https://example.com/textbook/|g' agent/noe-shikumi/note_drafts/*.md
```

- 教科書本文の丸写しは禁止。同一内容が母艦とnoteに重複すると母艦側が評価を失う。
  15本すべて、導入・例示・締めを教科書と変えた派生原稿として書いてある

## X 運用

`x_posts.json` は **NOE結婚設計室の `agent/x_posts.json` とは別アカウント・別キュー**である。
両者の投稿を混在させないこと（ペルソナが分離できず、両方の信頼を落とす）。

- 39本・全15章から分解。全投稿140字以内（日本語制限）
- type：insight（逆説）16 / structure（構造）13 / tips（手順）6 / confession（自己開示）3 / data（数値）1
- 決定式：`index = (JST日数差×2 + slot) % 39`、slot=0が朝・slot=1が夜
- data型は数値を1行目に置く（結婚設計室の実測で確認済みの勝ちパターン）
- confession型（自己開示）はこのチャンネル固有。信仰値は取り繕えない状態からしか生まれないため、
  当たった話だけを並べない。外した記録も同じ比率で出す

## 金軸アフィリエイトサイトについて（2026-07-30 判断：着手しない）

「教科書を核にした金軸アフィリサイト」は検討のうえ**見送り**とした。記録として残す。

### 見送りの理由

1. **教科書に検索需要がない。**「金は期待に払われる」を検索する人はいない。
   アフィリサイトに必要なのは機能値記事（比較・料金・やり方）を数百本積む作業であり、
   教科書があっても工数は1本も減らない
2. **noe-match が未離陸。**2026-06-26〜07-24 のGSC実測で238記事・9クリック・235表示。
   1つ目のドメインが評価される前に2つ目を立てるのは、AGENT.md 冒頭の軸展開モデル
   （「個人が同時に深く見られるサイトは実質1つ」）に正面から反する
3. **構造の矛盾。**アフィリは単価・承認・提携終了をASPが握る＝天井を他人が決める稼ぎ方であり、
   教科書第七章・第十三章が否定している側の報酬グラフに、信仰値資産を接続することになる

### 再検討する条件（すべて満たしたときのみ）

- noe-match が月間クリック数で離陸している（目安：月1,000クリック以上／収益が発生している）
- 商品層（自社商品）が稼働し、母艦→商品の導線が測定できている

### そのとき採る切り口（決めてある）

一般的な「副業」「投資」キーワードには入らない。SERPが金融メディアと企業運営サイトで埋まっており、
YMYL評価も最も厳しく、新規ドメインの個人には勝ち目がないため。

採るのは **「経理・総務・経営企画15年、会社の内側から見た給料の決まり方」** 一本。
教科書第五章がそのまま核になる。転職メディアは企業がクライアントなので
「原価が見えない業種ほど給料が高い」「大きいからではなく古いから高い」を書けない
＝ AGENT.md の「大手が書けない場所」原則に合致する。

受け皿案件：転職エージェント、年収診断、簿記・会計スキル講座、会計SaaS。
**投資助言（金商法）に触れる記事は書かない。**証券・FX案件は単価が高いが、
無登録の個人が推奨に踏み込むリスクがあるため、この切り口では扱わない。
