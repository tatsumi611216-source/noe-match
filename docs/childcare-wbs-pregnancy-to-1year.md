# 育児WBS：妊娠判明 〜 生後1歳（約21ヶ月）

**最終更新：2026-08-11**

妊娠判明から子どもが1歳になるまでに「いつ・誰が・何をするか」を月単位で分解したWBS。
行政手続き・医療・お金・モノの準備・育児実務・イベント・保活/仕事復帰を横断して、
"抜けたら詰む"タスクを法定期限付きで洗い出している。

---

## 0. このドキュメントの使い方

### 0-1. カテゴリ定義

| 記号 | カテゴリ | 内容 |
|:--|:--|:--|
| **A** | 手続き（行政） | 市区町村役所・保健センターへの届出 |
| **B** | 手続き（勤務先・保険） | 会社、健保組合、ハローワーク、民間保険 |
| **C** | 医療 | 健診、検査、予防接種、通院 |
| **D** | 準備（モノ・環境） | 購入、設置、安全対策 |
| **E** | 育児実務 | 日々のオペレーション、離乳食、睡眠、記録 |
| **F** | お金 | 給付金、控除、家計、教育資金 |
| **G** | イベント・記録 | 行事、写真、内祝い |
| **H** | 保活・キャリア | 保育園、育休、復職 |
| **I** | 夫婦運営 | 分担、コミュニケーション、メンタル |

### 0-2. 担当欄の表記

`母` / `父` / `2人` は一般的な例。
**動ける方が動く**のが原則なので、自分の家庭に合わせて書き換えて使うこと。
特に「A. 行政手続き」「B. 勤務先手続き」「D. 準備」は、産後の母体の状態を考えると
**父側に寄せておくほど産後が楽になる**。

### 0-3. ステータス欄

`☐ 未着手` → `◐ 進行中` → `☑ 完了` → `― 対象外`

### 0-4. 重要な前提

- 日本国内（会社員世帯）を前提。自営業・公務員は一部制度が異なる。
- **行政サービスは自治体差が非常に大きい**。金額・回数・対象は必ず住んでいる市区町村の
  公式サイトで確認すること。本WBSは「何を確認すべきか」のリスト。
- 制度は毎年4月に変わる。特に2026年4月からの変更（RSVワクチン定期接種化、
  こども誰でも通園制度、子ども・子育て支援金の徴収開始）は本文に反映済み。

## 1. クリティカルパス（絶対に落とせない法定期限）

ここだけは期限を過ぎると金銭的・手続き的な実害が出る。

| 期限 | タスク | 遅れた場合のリスク |
|:--|:--|:--|
| 妊娠11週頃まで | 妊娠届 → 母子健康手帳の交付 | 妊婦健診の公費補助（14回分）を取り逃す |
| 妊娠8〜12週 | 分娩予約 | **人気の産院は埋まる。里帰りは特に早く** |
| 妊娠28週0日〜36週6日 | RSV母子免疫ワクチン（2026年4月〜定期接種＝無料） | 窓口が閉じる。乳児の重症化リスク |
| 妊娠34週0日 | 産前休業開始（希望する場合） | ― |
| 出産日を含めて**14日以内** | **出生届** | 戸籍未登録。過料の対象 |
| 出産日の翌日から**15日以内** | **児童手当の認定請求** | **15日特例を外すと申請月の翌月分から。1ヶ月分（1〜3万円）消える** |
| 出生後14日以内 | 低体重児出生届（2500g未満の場合） | 支援につながらない |
| 出生後すみやか | 健康保険の加入（社保は勤務先、国保は14日以内） | 1ヶ月健診・乳児医療証に間に合わない |
| 産後8週間以内 | 産後パパ育休（出生時育児休業）※申出は原則2週間前 | 取得機会を失う |
| 育休開始から4ヶ月を経過する日の属する月末 | 育児休業給付金の申請 | 給付金が受け取れない |
| 生後**14週6日**まで | **ロタウイルスワクチン1回目** | **これを過ぎると生涯接種不可（腸重積リスクのため）** |
| 生後2ヶ月の誕生日 | 予防接種デビュー（同時接種4本） | 以降のスケジュールが全部後ろ倒し |
| 出産翌年の2〜3月 | 確定申告（医療費控除） | 数万円の還付を逃す（5年は遡れる） |
| 入園前年の10〜12月 | 認可保育園の一次申込 | **4月入園を1年逃す。育休延長の可否にも直結** |

## 進め方のルール

1. **新しい食材は1日1種類・小さじ1から・午前中**（何かあれば小児科が開いている時間に）
2. アレルギー特定原材料（卵・乳・小麦・そば・落花生・えび・かに・くるみ）は特に慎重に、しかし**遅らせない**
3. 味付けはほぼ不要。1歳までは薄味。
4. **1歳未満ははちみつ禁止**（乳児ボツリヌス症、死亡例あり）
5. **生もの（刺身・生卵）は3歳頃まで避ける**
6. **窒息リスク食材**：もち、ナッツ類（5歳未満は丸ごとNG）、ミニトマト・ぶどう（4等分）、こんにゃくゼリー、飴
7. **ベビーフードは積極的に使う**。手作りが偉いわけではない。栄養設計は市販品のほうが安定している
8. 冷凍ストック運用：まとめて作る → 製氷皿型容器で小分け冷凍 → 1週間以内に使い切る
