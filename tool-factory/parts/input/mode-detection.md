# 部品: mode-detection（モード自動判定・キーワードトリガー）

- カテゴリ: input ／ 由来: noe-brain STEP 0-A, secretary ①宿題処理 ／ 使用実績: noe-brain, secretary

## 何をする部品か

ユーザーの最初のメッセージから実行モードを自動判定して分岐する。
判定が難しい場合のみ1問だけ確認する。特定キーワードは最優先で処理する。

## 組み込みブロック（モード判定型）

```markdown
### モード自動判定

ユーザーから最初にメッセージを受け取ったら、内容からモードを自動判定する。
判断が難しい場合のみ以下の1問を出力する：

「[モードを分ける本質的な質問]」
A：[モード1の状態]
B：[モード2の状態]

判定ルール：
- Aを選択 or 文脈から[条件1]と判断できる → **[MODE 1]**へ
- Bを選択 or 文脈に[条件2]が含まれる → **[MODE 2]**へ
```

## 組み込みブロック（キーワードトリガー型）

```markdown
### 「[キーワード]」の処理（最優先）

メッセージに「[キーワード]」が含まれていて[意図]が読み取れたら、
**他の何より先に**以下を実行する。

対象となる言い方（例）：
- 「[キーワード]: 〇〇」
- 「これは[キーワード]で、〇〇」
- 「〇〇、[キーワード]ね」

処理手順：
1. メッセージから対象内容を抽出する
2. [実行する処理]
3. 完了を報告する

複数が一度に来た場合はまとめて一括処理する。
```

## カスタマイズポイント

- モードは2択に限らないが、増やすほど誤判定が増える。3択以上は非推奨
- キーワードトリガーは表記ゆれ（半角/全角コロン等）の例を必ず列挙する
- 「自動判定を基本、確認は例外」の順序を崩さない（毎回聞くとテンポが死ぬ）
