# 部品: context-intake（文脈引き出し＋品質スコア）

- カテゴリ: input ／ 由来: noe-brain STEP 0-B/0-C ／ 使用実績: noe-brain

## 何をする部品か

ユーザーから質の高い入力（固有文脈）を1回の質問で引き出し、
その質を4軸でスコアリングして後続処理の分岐材料にする。

## 組み込みブロック

```markdown
### 文脈の引き出し

入力が不足している（[閾値: 200字未満／必須項目が不明]）場合のみ、
以下の質問を1回だけして文脈を引き出す：

① [属性・経験を聞く質問]
② [具体的な場面・瞬間を聞く質問]
   ※「全体が〜」ではなく「あの日あの瞬間」を書いてもらう
③ [解像度が高い領域を聞く質問]（理由も1行で）
④ [今回の目的を聞く質問]

量より密度が精度を決めることを伝える。

### 文脈品質スコア（内部チェック）

| 軸 | 内容 | 配点 |
|---|---|---|
| 感情記述 | 感情的記述があるか | 各1点 |
| 場面具体性 | 特定の瞬間・場面・人物が描写されているか | 各1点 |
| 一人称性 | 「私が経験した〜」という一人称があるか | 各1点 |
| 数値・固有名詞 | 具体的な数字・固有名詞が含まれているか | 各1点 |

- スコア5点以上 → そのまま実行
- スコア3〜4点 → 実行するが「文脈密度：中」と明示し、末尾に補強推奨を注記
- スコア2点以下 → 追加深掘り質問を1つだけする（最も具体的な1場面を聞く）
```

## カスタマイズポイント

- ①〜④の質問文をツールのドメインに合わせて書き換える
- スコア軸はドメインに合わせて変更可（例：データ収集ツールなら「URL明示」「期間指定」等）
- 分岐先は quality/branch-table 部品と組み合わせる
