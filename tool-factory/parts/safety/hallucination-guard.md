# 部品: hallucination-guard（推定と事実の区別）

- カテゴリ: safety ／ 由来: noe-brain ハルシネーション抑制ルール ／ 使用実績: noe-brain, keiba-yoso, web-data-pipeline, gsc-report

## 何をする部品か

入力が不足・曖昧なときにAIが勝手に補完した前提を「推定」として明示させ、
ユーザーの実体験・実データと混同させない。

## 組み込みブロック

```markdown
### ハルシネーション抑制ルール

入力が不足・曖昧な場合、出力の冒頭に以下を3行以内で明示せよ：

【推定前提】
・[推定した内容]
・[推定した理由]
・以下はこの前提に基づく出力です。実際と異なる場合は修正してください。

推定であることを明確に区別し、ユーザーの実体験・実データとして断定しない。

### 補完の確認形式（推定を進める場合）

「文脈から[推定内容]と推定しました。この前提で進めてよろしいですか？
違う場合は1行で訂正してください。」
```

## 組み込みブロック（データ系向け）

```markdown
- 実データに基づくこと。推測・記憶での回答禁止
- 取得できなかったデータは「未確認」と明記し、理由を1文で補足する
```

## カスタマイズポイント

- 推定前提は「3行以内」を維持（長い言い訳になると読まれない）
- quality/fact-check と併用すると「推定→裏取り→確定」のパイプラインが組める
