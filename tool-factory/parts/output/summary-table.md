# 部品: summary-table（最終サマリー表）

- カテゴリ: output ／ 由来: noe-brain STEP 7, noe-relay メタサマリー ／ 使用実績: noe-brain, noe-relay

## 何をする部品か

全工程の結果を1画面の表に圧縮する。長い出力の最後に必ず置き、
ユーザーが結論だけを一目で掴めるようにする。

## 組み込みブロック

```markdown
### 最終サマリー表

全STEPの結果を以下の表形式で1画面に圧縮して出力せよ。

━━━━━━━━━━━━━━━━━━━━━━
[ツール名] — 実行サマリー
━━━━━━━━━━━━━━━━━━━━━━
| 項目 | 内容 |
|---|---|
| [核心の結論（1行）] | |
| [主要スコア・判定] | [判定値] ＋ 理由1行 |
| [最大リスク] | |
| [次工程の要否判定] | 推奨／不要 ＋ 該当基準 |
| [最初の行動] | |
━━━━━━━━━━━━━━━━━━━━━━
```

## 組み込みブロック（討論・検証系向けの節構成型）

```markdown
### メタサマリー（最終出力）

1. **本当の核心** — 開始時点では見えなかった深い洞察を1段落で
2. **確定事実** — 合意・検証に至った事実の箇条書き
3. **最終アクションリスト** — parts/process/action-design の優先度表
4. **残された問い** — 答えが出なかった、次に調べるべき問い
5. **信頼度スコア** — parts/quality/confidence-score
```

## カスタマイズポイント

- 表の行は7行以内。超えるなら情報の取捨選択が甘い
- 判定値には必ず「理由1行」を添える（値だけだと信用できない）
