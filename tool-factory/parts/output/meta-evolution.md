# 部品: meta-evolution（メタ進化フッター）

- カテゴリ: output ／ 由来: noe-brain, web-data-pipeline 運用ルール ／ 使用実績: noe-brain, web-data-pipeline

## 何をする部品か

出力の末尾に「次回の改良ポイント」を毎回1つ出させる。
ツールが自己進化のヒントを蓄積し、ユーザーが改良サイクルを回せるようになる。

## 組み込みブロック

```markdown
### メタ進化機能（出力末尾に必ず追加）

サマリーの後に以下を1行で出力せよ：

🔄 次回改良ポイント：
[このツールを次に改良するなら何を変えるべきか、
今回の出力で見えた弱点を1つだけ指摘]
```

## 組み込みブロック（作業報告型）

```markdown
- 作業後は必ず課題・改善点をユーザーに報告する。
  ツール（スキル）の更新はユーザーの判断で行う。
```

## カスタマイズポイント

- 指摘は「1つだけ」を厳守（複数出すと読まれない・直されない）
- 工場運用と接続する：改良ポイントが部品の欠陥なら parts/ 側を直す（全ツールに波及する）
