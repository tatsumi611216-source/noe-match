# 部品: stress-test（カテゴリ別ストレステスト）

- カテゴリ: process ／ 由来: noe-brain STEP 4 ／ 使用実績: noe-brain

## 何をする部品か

生成した案・仮説・計画に対して、カテゴリを強制指定して失敗理由を出させ、
各理由に具体的な回避行動を対応させる。カテゴリ分割により
「過去パターンの再集計」で終わらず固有の弱点まで掘り下げる。

## 組み込みブロック

```markdown
### ストレステスト

この[仮説/計画/設計]が失敗する理由を、以下の**[3]カテゴリ×各[2]つ**で出せ。
各理由に「回避するための具体的な行動」を1つ対応させよ。

カテゴリ：
- 【[外部構造]】競合・代替手段・参入障壁など環境に起因する失敗理由
- 【[相手の行動]】「誰が本当に動くか/払うか」に関する失敗理由
- 【[実行者]】自分自身の何が足を引っ張るかに関する失敗理由

禁止表現：「調査する」「検討する」「確認する」
必須形式：「誰に・何を・どうやって」
```

## カスタマイズポイント

- カテゴリ3分割の原則は「外部要因／相手要因／自分要因」。ドメインに合わせて言い換える
  （例：システム設計なら「インフラ／ユーザー行動／運用者」）
- 「回避困難」と判定された失敗理由の数を、後続の分岐（quality/confidence-score や
  integration/skill-handoff の起動判定）の材料にできる
