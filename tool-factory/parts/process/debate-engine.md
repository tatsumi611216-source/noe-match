# 部品: debate-engine（討論エンジン）

- カテゴリ: process ／ 由来: noe-relay ／ 使用実績: noe-relay

## 何をする部品か

論題から討論者2名＋審判を自動設計し、ターン制討論＋審判介入で
論点を多角的に掘り下げる。単独の視点では見えない穴（デッドアングル）を外から壊す。

## 組み込みブロック（要約版 — フル仕様は noe-relay SKILL.md を参照）

```markdown
### 自動キャスティング

論題を受け取ったら：
1. 論題を分解する（業界/ドメイン・核心的な問い・最大の対立軸）
2. 論者A（懐疑側）：最も鋭い批判ができる専門家。数字で殴れる人物が理想
3. 論者B（肯定側）：最も実践的な攻め手を出せる専門家。一次情報を持てる人物が理想
4. 審判：両者のドメインを俯瞰できる第三者
各人物は職業・経歴・性格・口調を3行以内で設定する。

### 討論ルール（1ラウンド8ターン）

- 奇数ターン=論者A、偶数ターン=論者B
- 具体性ルール（parts/quality/concreteness-rules）を全発言に適用
- 審判はターン3・6の直後に介入：抽象発言の指摘・数値出典の疑義・キャラブレ指摘・
  次に掘るべき論点の命令。**絶対に決着をつけない**
- ラウンド終了後にサマリー（論点の核心・両者の最強の一手・裏取りが必要な数字リスト・未解決争点）

### ラウンド間インターミッション

- parts/quality/fact-check で数字を裏取り・補正
- 未解決争点から次ラウンド論題を自動決定
- 必要ならキャラに追加設定を1つ付与（元のキャラは変えない）
```

## カスタマイズポイント

- ラウンド数・ターン数は論題の重さで調整（軽い検証なら1ラウンド4ターンで十分）
- 討論者を3名以上にする場合は発言順と審判の介入頻度を再設計する
- 出力が長くなるので、最終判断に使うのはメタサマリーのみとする設計を推奨
