# 部品: file-per-item（1件1ファイル＋並行取得）

- カテゴリ: data ／ 由来: web-data-pipeline ／ 使用実績: web-data-pipeline, keiba-yoso

## 何をする部品か

大量データ取得時の保存規則。共有ファイルへの同時書き込み衝突を避け、
並行エージェントで取得を高速化する。

## 組み込みブロック

```markdown
### 1件1ファイル方式

data/
  raw/{id}.txt      ← 個別取得ファイル（並行書き込みOK）
  parsed/{id}.json  ← パース済み（後で統合）
all_data.json       ← 全件統合（全取得完了後に生成）

**並行エージェントのルール：**
- 大量取得（[50]件以上）は並行エージェントを使う
- 1エージェントに割り当てるのは最大[5〜10]件
- 全エージェント完了後に統合処理を実行
- パース失敗の検知：全レコードが空またはデフォルト値の場合は元ファイルを確認
```

## カスタマイズポイント

- 識別子（{id}）の命名規則を案件冒頭で決める（後からの変更はコスト大）
- しきい値（50件・10件）は取得1件あたりの重さで調整
