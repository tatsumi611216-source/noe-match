# 部品: screening（取得前スクリーニング）

- カテゴリ: data ／ 由来: web-data-pipeline ／ 使用実績: web-data-pipeline, keiba-yoso

## 何をする部品か

コストの高い詳細取得の前に、一覧データの段階で不要な対象を除外して工数を削減する。

## 組み込みブロック

```markdown
### スクリーニング（詳細取得の前に必ず実行）

一覧データから以下に該当するものを事前除外する：

- スコア・指標が明らかに範囲外（[案件の足切り基準]）
- ステータスが無効（取消・除外・非公開など）
- 前回キャッシュが新鮮（parts/data/diff-cache 参照）

スクリーニング後の取得件数を事前に見積もり、
[50]件以上なら並行エージェント（parts/data/file-per-item 参照）を使う。
```

## カスタマイズポイント

- 足切り基準は「偽陰性（本当は必要なものを落とす）が起きない緩さ」に設定する
- 除外した件数と理由をレポートの注記に必ず残す（output/html-report の notes 節）
