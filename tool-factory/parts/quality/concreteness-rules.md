# 部品: concreteness-rules（抽象論禁止・具体性強制）

- カテゴリ: quality ／ 由来: noe-brain 出力上の注意, noe-relay 発言ルール ／ 使用実績: noe-brain, noe-relay

## 何をする部品か

AIの出力が「一般論の再集計」に落ちるのを防ぎ、固有名詞・数値・具体的手順を強制する。
生成系ツールの品質を最も左右する基本部品。

## 組み込みブロック

```markdown
### 具体性ルール（全出力に適用）

**禁止表現：**
- 「一般的には」「多くの場合」「よく言われるように」
- 「調査する」「検討する」「確認する」「まず〇〇を調べてから」
- 抽象名詞（価値・共感・可能性・本質等）の連続3回以上の使用

**必須要素：**
- 固有名詞・数値・具体的な人物像でのみ語ること
- 数値を出すときは根拠（情報源・計算式）を必ず併記
- 行動は「誰に・何を・どうやって・いつまでに」の形式で書くこと
```

## 組み込みブロック（対話・討論系向けの追加ルール）

```markdown
- 「一般的には〜」禁止。「俺が○○してた時は」「うちの業界では」という一次情報形式で語ること
- 各ターンで新情報を1つ以上追加すること。同じ論点の言い換え禁止
- 1ターン最大[200]字。超えた場合は打ち切って次へ
```

## カスタマイズポイント

- 禁止語リストはドメインごとに追加する（例：投資系なら「絶対儲かる」等の断定も禁止）
- 文字数上限は出力形式に合わせて調整
- 検証役（審判・レビュアー）がいる構成では、このルール違反を指摘する役割を審判に持たせる（process/debate-engine 参照）
