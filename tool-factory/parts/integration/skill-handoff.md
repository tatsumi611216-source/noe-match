# 部品: skill-handoff（スキル間連携）

- カテゴリ: integration ／ 由来: noe-brain STEP 5/5-R ／ 使用実績: noe-brain, noe-relay

## 何をする部品か

ツールAの処理途中で「別ツールBにかけるべきか」を機械的に判定し、
Bへの起動コマンドとBからの結果合流コマンドを自動生成する。
ツール同士をパイプでつなぐための接続部品。

## 組み込みブロック

```markdown
### [連携先ツール]要否の自動判定

以下の基準を順番にチェックし、各基準に【該当／非該当】と判定理由を1行で述べよ。

| 基準 | 内容 |
|---|---|
| 基準1 | [連携が必要になる条件1] |
| 基準2 | [連携が必要になる条件2] |
| ... | |

判定ルール：1つでも「該当」があれば → 「✅ [連携先]推奨」、全て「非該当」→ スキップして次へ

### 起動コマンドの生成（推奨判定時のみ）

以下をそのまま次のチャットに貼ることで[連携先]が即起動する形式で出力する：

「[連携先スキル名]を起動せよ。
[引き渡すパラメータ1]：[値]
[引き渡すパラメータ2]：[値]
[連携先に適用させる制約ルール]」

### 合流命令の生成

[連携先]の結果を受け取ったら、以下を貼ることで本ツールの[続きのSTEP]が起動する：

「[連携先]の結果を受けて[本ツール名] [続きのSTEP]を実行せよ。
[結果スコア]：[値]
[確定事実]：[そのまま貼る]」

結果スコアによる分岐：[B以上]→そのまま続行／[C以下]→[改善施策]を組み込んで続行
```

## カスタマイズポイント

- 判定基準は「自分のデッドアングル（単独では検証できない領域）」を列挙する
- 起動コマンドは**コピペ1発で動く完全な形式**にする（ユーザーに編集させない）
- 連携先に制約ルール（quality/concreteness-rules 等）を明示的に引き渡すと出力が暴れない
