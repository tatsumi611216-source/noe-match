# 部品: scheduled-task（定期タスク組み込み）

- カテゴリ: integration ／ 由来: web-data-pipeline, morning ／ 使用実績: web-data-pipeline, keiba-yoso, morning

## 何をする部品か

ツールを定期実行タスクとして自動化する際の標準フロー。
重い処理を時間帯で3分割し、無人実行時の注意点を押さえる。

## 組み込みブロック

```markdown
### 定期タスクへの組み込み

朝のキャッシュタスク（軽量）:
  - 一覧から当日対象を取得 → スクリーニング → 差分キャッシュ照合 → 新規分だけ詳細取得
  - {日付}_cache.json に保存

日中の分析タスク:
  - キャッシュを読み込んでスクリプト実行 → レポート生成

夜の突合タスク（結果確認がある案件）:
  - 結果データを取得して予測・計画と照合
  - 精度指標を蓄積（ログに追記）

### 無人実行時のルール

- 定期タスクのプロンプトには言語・出力先・対象を明記する（無人実行では推測できない）
- 対話が必要な処理（確認・サジェスト）は無人実行ではスキップし、成果物の生成に徹する
```

## カスタマイズポイント

- 3分割は必須ではない。結果突合がない案件は朝＋日中の2タスクでよい
- 精度指標の蓄積先（ログファイル／Notion）を案件で決める（integration/notion-task と接続可）
