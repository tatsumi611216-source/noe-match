# 案件カスタマイズガイド

このスキルをベースに個別案件スキルを作るときの手順とサンプルコード集。

---

## カスタマイズの流れ

1. このスキルをコピーして案件名のディレクトリを作る
2. SKILL.md の frontmatter (name/description) を案件名に更新
3. `analyze.py` を案件に合わせて実装
4. `generate_report.py` を案件に合わせて実装
5. SKILL.md の案件固有セクション（URL、フィールド定義、スコア基準）を追記

---

## サンプル: analyze.py の雛形

```python
"""
analyze.py — [案件名] 分析スクリプト

Usage:
  python analyze.py input.json --output results.json
"""
import json, sys, argparse

def score_item(item: dict) -> float:
    """アイテムのスコアを計算する。高いほど注目度が高い。"""
    score = 0.0
    
    # ここに案件固有のスコアリングロジックを実装
    # 例: 価格が安いほど高スコア
    # price = item.get('price', 0)
    # if price < 10000: score += 2
    # elif price < 50000: score += 1
    
    return score

def analyze(data: dict) -> dict:
    """データ全体を分析してスコアリングする。"""
    items = data.get('items', [])
    
    scored = []
    for item in items:
        item['score'] = score_item(item)
        scored.append(item)
    
    scored.sort(key=lambda x: x['score'], reverse=True)
    
    return {
        'total': len(scored),
        'top_items': scored[:10],
        'all_items': scored
    }

if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('input')
    parser.add_argument('--output', '-o')
    args = parser.parse_args()
    
    with open(args.input) as f:
        data = json.load(f)
    
    result = analyze(data)
    out = json.dumps(result, ensure_ascii=False, indent=2)
    
    if args.output:
        with open(args.output, 'w') as f:
            f.write(out)
        print(f"Saved: {args.output}")
    else:
        print(out)
```

## サンプル: generate_report.py の雛形

```python
"""
generate_report.py — HTMLレポート生成

Usage:
  python generate_report.py results.json --date "2026年4月10日" --output report.html
"""
import json, argparse
from datetime import datetime

TEMPLATE = """<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>{title}</title>
<style>
  body {{ background: #1a1a2e; color: #e0e0e0; font-family: sans-serif; margin: 0; padding: 20px; }}
  h1 {{ color: #4fc3f7; border-bottom: 2px solid #4fc3f7; padding-bottom: 8px; }}
  .summary {{ display: flex; gap: 20px; margin: 20px 0; }}
  .stat {{ background: #16213e; padding: 15px 20px; border-radius: 8px; text-align: center; }}
  .stat-value {{ font-size: 2em; font-weight: bold; color: #4fc3f7; }}
  .stat-label {{ font-size: 0.85em; color: #aaa; }}
  table {{ width: 100%; border-collapse: collapse; margin: 20px 0; }}
  th {{ background: #16213e; padding: 10px; text-align: left; color: #4fc3f7; }}
  td {{ padding: 8px 10px; border-bottom: 1px solid #333; }}
  tr:hover {{ background: #16213e; }}
  .score-bar {{ height: 8px; background: #333; border-radius: 4px; overflow: hidden; }}
  .score-fill {{ height: 100%; background: #4fc3f7; border-radius: 4px; }}
  .badge {{ display: inline-block; padding: 2px 8px; border-radius: 12px;
            font-size: 0.8em; font-weight: bold; }}
  .badge-high {{ background: #1b5e20; color: #69f0ae; }}
  .badge-mid  {{ background: #e65100; color: #ffcc02; }}
  .badge-low  {{ background: #4a148c; color: #ea80fc; }}
</style>
</head>
<body>
<h1>{title}</h1>
<p style="color:#aaa">{date} 生成</p>

<div class="summary">
  <div class="stat">
    <div class="stat-value">{total}</div>
    <div class="stat-label">総件数</div>
  </div>
  <div class="stat">
    <div class="stat-value">{top_count}</div>
    <div class="stat-label">注目件数</div>
  </div>
</div>

<h2>注目トップ10</h2>
<table>
  <thead>
    <tr>
      <th>#</th>
      <th>名称</th>
      <th>スコア</th>
      <th>詳細</th>
    </tr>
  </thead>
  <tbody>
    {rows}
  </tbody>
</table>

<p style="color:#666;font-size:0.8em">Generated by web-data-pipeline skill</p>
</body>
</html>"""

def score_badge(score: float, max_score: float) -> str:
    ratio = score / max_score if max_score > 0 else 0
    if ratio >= 0.7:
        return '<span class="badge badge-high">高</span>'
    elif ratio >= 0.4:
        return '<span class="badge badge-mid">中</span>'
    else:
        return '<span class="badge badge-low">低</span>'

def generate(results: dict, title: str, date: str) -> str:
    items = results.get('top_items', [])
    max_score = max((i.get('score', 0) for i in items), default=1)

    rows = []
    for rank, item in enumerate(items, 1):
        score = item.get('score', 0)
        bar_width = int(score / max_score * 100) if max_score > 0 else 0
        badge = score_badge(score, max_score)
        
        # ここを案件に合わせてカスタマイズ
        name = item.get('name', item.get('id', f'Item {rank}'))
        detail = ' / '.join(f"{k}={v}" for k, v in item.items()
                           if k not in ('name', 'id', 'score', '_raw_values', '_raw_block'))
        
        rows.append(f"""
        <tr>
          <td>{rank}</td>
          <td><strong>{name}</strong></td>
          <td>
            {badge}
            <div class="score-bar" style="width:120px;display:inline-block;vertical-align:middle">
              <div class="score-fill" style="width:{bar_width}%"></div>
            </div>
            <span style="margin-left:8px;color:#aaa">{score:.2f}</span>
          </td>
          <td style="font-size:0.85em;color:#aaa">{detail}</td>
        </tr>""")

    return TEMPLATE.format(
        title=title,
        date=date,
        total=results.get('total', 0),
        top_count=len(items),
        rows='\n'.join(rows)
    )

if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('input')
    parser.add_argument('--title', default='データ分析レポート')
    parser.add_argument('--date', default=datetime.now().strftime('%Y年%m月%d日'))
    parser.add_argument('--output', '-o', default='report.html')
    args = parser.parse_args()

    with open(args.input) as f:
        results = json.load(f)

    html = generate(results, args.title, args.date)
    with open(args.output, 'w', encoding='utf-8') as f:
        f.write(html)
    print(f"Saved: {args.output}")
```

## keiba-yosoを例にした対応表

| 汎用スキルの概念 | keiba-yosoでの実装 |
|---|---|
| 対象リスト取得 | NARレース一覧（race_list.html）|
| スクリーニング | オッズ分布スコア + 馬フィルタ（1.3倍以下/100倍超除外）|
| 個別データ取得 | 各馬のhorse page（db.netkeiba.com）|
| パース | parse_horse_results.py（AT/plain/CSV自動判定）|
| 差分キャッシュ | {日付}_nar_cache.json の horse_id 照合 |
| 分析スクリプト | calc_ev.py（EV = 推定勝率 × オッズ - 1）|
| レポート生成 | generate_report.py（ダークテーマ、EVバー、Half-Kellyポートフォリオ）|

## よくある案件別カスタマイズポイント

### 不動産価格トラッキング
- 対象リスト: SUUMO/athomeの検索結果ページ
- スクリーニング: 価格帯・築年数フィルタ
- 分析スコア: 坪単価 × 駅距離 × 築年数の重み付け
- 差分キャッシュ: 物件IDで照合（新着のみ取得）

### 株スクリーニング
- 対象リスト: スクリーナーAPIまたはWebページ
- スクリーニング: 時価総額・出来高フィルタ
- 分析スコア: PER・PBR・ROEの複合スコア
- 差分キャッシュ: 銘柄コードで照合（当日の決算発表分は再取得）

### EC価格比較
- 対象リスト: 商品カテゴリページ
- スクリーニング: 価格帯・評価数フィルタ
- 分析スコア: 価格/評価の比率
- 差分キャッシュ: 商品IDで照合（価格変動があれば再取得）
