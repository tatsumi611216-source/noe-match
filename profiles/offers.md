## 自己紹介（目安1,000字前後・そのまま貼る）

```
■ 使える技術（すべて副業・自主開発で手を動かしているもの）

フロント／バック：Next.js 14、React 18、TypeScript、Node.js（Express）、Prisma、Tailwind CSS
データ：Python（pandas / numpy）、日次バッチのデータ収集パイプライン
インフラ・SaaS：Vercel、Firebase、Stripe、GitHub Pages、Netlify、GA4、Search Console
AI：プロンプト設計、DB連携、多視点レビューの自動化（こちらは現職の実務）

■ 副業で作って、今も運用しているもの

・業務管理ダッシュボード（Next.js 14 / React 18 / TypeScript / Prisma / Tailwind CSS）
　定期バッチでデータを収集し、指標を可視化。Vercel上で常時運用しています。

・決済連携のあるチャットボット（Node.js（Express）/ Firebase / Stripe）
　ユーザー管理と課金処理を含みます。

・独自ドメインの公開サイト複数（GitHub Pages / Netlify / Vercel）
　GA4・Search Consoleと連携し、コンテンツを定期更新しています。

・日次バッチ・データ収集パイプライン（Python）

・需要予測のPoC
　間欠需要予測（Croston法、SBA補正、TSB法、SBC分類）を英語の原典論文にあたって実装。
　60SKU×約4年の日次データで予測パイプラインを構築し、46ヶ月分の暦月バックテストで検証。
　rolling origin CV、分位点の被覆率検証まで行っています。

いずれも業務外での独学・自主開発です。エンジニアとしての職務経験はありません。
そこは先に申し上げたうえで、成果物と検証の中身でご判断いただければと思っています。

■ 本業（技術以外の強み）

事業会社の管理部門14年（経理・総務・経営企画）。中期経営計画・単年予算の策定、
月次の予実管理、決算開示・IR資料の作成を担当してきました。
現在は経営コンサルティングファームのマネージャーとして、管理部門のハンズオン支援に従事。
AIとデータベースを統合した業務効率化基盤の設計・構築、新規マッチングプラットフォームの
立ち上げ、7名体制のBPO案件のプロジェクトマネジメントを担当しています。

「この指標は何を見るための数字なのか」「この数字は何を言えて何を言えないのか」を
詰めたうえで実装できるところが、他のエンジニアとの差だと思っています。

■ 副業で関わりたいこと

・社内向けの業務系Webアプリ、管理画面の新規開発と改修
・データ収集・集計の自動化、ダッシュボードへの配信
・KPI・予実管理の設計と、それを支える実装
・需要予測、時系列分析のPoC
・生成AIを組み込んだ業務ワークフローの設計と実装

受託で切り出された機能単位より、「何を測るべきか」から入れる案件を歓迎します。

■ 進め方

前提と限界を先にお伝えします。検証の結果として不利な事実が出た場合もそのまま報告します。
業務は個人で遂行し、第三者への再委託は行いません。
```
