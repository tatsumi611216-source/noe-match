## 自己紹介（目安800字前後・そのまま貼る）

```
副業でWebアプリケーションとデータ基盤を、設計から実装・公開・運用まで一人で作っています。
本業は事業会社の管理部門14年（経理・総務・経営企画）と、現在は経営コンサルティング
ファーム（従業員約110名）のマネージャーです。

副業の開発物はいずれも現在も稼働しています。

・業務管理ダッシュボード（Next.js 14 / React 18 / TypeScript / Prisma / Tailwind CSS）
　定期バッチでデータを収集し、指標を可視化。Vercel上で常時運用
・決済連携のあるチャットボット（Node.js（Express）/ Firebase / Stripe）
　ユーザー管理と課金処理を含む
・独自ドメインの公開サイト複数（GitHub Pages / Netlify / Vercel）
　GA4・Search Consoleと連携し、コンテンツを定期更新
・日次バッチ・データ収集パイプライン（Python）
・需要予測のPoC：間欠需要予測（Croston法、SBA補正、TSB法、SBC分類）を英語の原典論文に
　あたって実装。60SKU×約4年の日次データでパイプラインを構築し、46ヶ月分の暦月
　バックテストで検証。rolling origin CV、分位点の被覆率検証まで実施

これらは業務外での独学・自主開発で、エンジニアとしての職務経験はありません。
先にお伝えしたうえで、成果物と検証の中身でご判断いただきたいと思っています。

本業側では、AIとデータベースを統合した業務効率化基盤の設計・構築、新規マッチング
プラットフォームの立ち上げ、7名体制のBPO案件のプロジェクトマネジメントを担当しています。
BPO案件は主力メンバーの離職で業務が停滞した状態からPMに着任し、全業務フローを棚卸しして
属人化した工程を標準マニュアル化、内製化まで到達させました。

管理部門では中期経営計画・単年予算の策定、月次の予実管理、決算開示・IR資料の作成を
担当してきました。「この数字が何を言えて何を言えないか」を詰めたうえで実装できる点が、
他の副業エンジニアとの違いだと考えています。
```
