## 自己紹介（目安1,000字前後・そのまま貼る）

```
副業でWebアプリとデータ収集・分析の仕組みを、設計から実装・運用まで一人で作っています。
本業は事業会社の管理部門14年（経理・総務・経営企画）と、現在は経営コンサルティング
ファームのマネージャーです。

■ 副業でつくって、今も動かしているもの

・業務管理ダッシュボード
　Next.js / React / TypeScript / Prisma。データを定期的に自動収集して指標を可視化。
　クラウド上で常時運用しています。

・決済つきチャットボット
　Node.js / Firebase / Stripe。ユーザー管理と課金処理を含みます。

・独自ドメインのWebサイト複数
　GitHub Pages / Netlify / Vercel。GA4・Search Consoleと連携して定期更新。

・日次のデータ収集バッチ（Python）
　毎日データを取得し、整形して配信するところまで。

・需要予測の技術検証
　「たまにしか売れない商品」の予測手法を英語の原論文から実装。
　60商品×約4年の日次データで組み、46ヶ月分さかのぼって検証しました。

いずれも業務外での独学・自主開発です。予測分析を職務として担当した経験はありません。
そこは先にお伝えしたうえで、検証の中身でご判断いただければと思っています。

■ 本業で積んだこと

・予算の策定と実績差異の分析を14年（中期経営計画、単年予算、月次予算管理）
・AIとデータベースをつないだ業務効率化基盤の設計・構築（現職）
・7名体制の事務作業BPO案件のプロジェクトマネジメント。停滞状態から入り、
　全工程を洗い出して手順書化し、社内で回せる状態まで持っていきました
・社内ペーパレス化プロジェクトのリーダー（紙の書類7割削減）

■ 進め方

前提と限界を先にお伝えします。検証の結果、自分の方法が既存のやり方に負けていた場合も
そのまま報告します。決算開示やIR資料を作ってきたので、都合の良い数字だけを見せない
ことは習慣になっています。

作業は個人で行い、再委託はしません。

■ ご連絡・稼働について

正社員として勤務中のため、平日日中は制約があります。
確保できる時間は平日 7:00-9:00 / 12:00-13:00 / 19:00-23:00、土日祝は事前調整で終日です。
メッセージは日中も随時確認し、当日中に返信します。
```
