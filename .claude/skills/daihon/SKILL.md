# 台本執筆スキル（AI大学系トンマナ）

このスキルが読み込まれている間、台本・シナリオの出力は以下に**無条件で**従う。
ユーザーのプロンプトが短くても、この層が品質を担保する。

## 1. 文体（実測値。感覚で書かない）

- 一文は平均40字前後。10〜80字で大きく揺らす（変動係数0.5以上）
- 80字を超える文は書かない。声に出してつっかえる文は書かない
- ですます調。語尾の主軸は「〜すよね」「〜んです」。
  「〜きます」「〜ください」「〜ました」で回し、同じ語尾を3連続させない
- 視聴者の呼びかけは「皆さん」で統一
- 3発話に1回は具体的な数字を入れる
- 接続は「実は」「ちょっと」「逆に言うと」「で、」を使う
- 体言止めは1章2回まで

## 2. 禁止表現（1つでも出したら書き直し）

「〜ではないでしょうか」「〜と言えるでしょう」「いかがでしたか」「参考になれば」
「本記事では」「まとめると」「重要です」「〜が求められます」「近年」「昨今」
「様々な」「革新的」「シームレス」「目覚ましい」「多岐にわたる」
「活用する」「実現する」は具体的な動詞に置き換える。

## 3. 構造技法（08_技法カタログ.md の要約）

- **コールドオープン**：挨拶より先に、受益か損失を3文以内で。ジングル・名乗りはその後
- **本数の約束**：冒頭で「今日は◯つ」と総量宣言。章の頭でも「◯つ目は」
- **定型リフレイン**：項目の切り替えは毎回一言一句同じ文型
- **1項目=6ステップ**：リフレイン＋名前→一言定義→共感orリスク→実演→効能確認→注意or区別
- **共感→実は**：教える前に「〜ってありますよね」、直後に「実は」で裏切る
- **効能確認**：手順の直後に必ず「たったこれだけで〜」
- **揮発する事実の抽象化**：変わりやすい名前・価格は役割で教える
  （「名前はよく変わるので、早い・じっくり・コード用の3役で覚えてください」）
- **混乱の先回り**：似た概念が2つ出たら、聞かれる前に自分から区別する
- **行動指示のその場化**：「あとで」ではなく「動画を止めて今」
- 失敗談と反論の先回りは**1本に1〜2回だけ**。毎章入れない

## 4. 事実の扱い（絶対）

- 知識で事実・数値・固有名詞を断定しない。書く場合は必ず【要確認：内容】を付ける
- 出典が確認できないものは「一般的に」でぼかさず、書かない
- ユーザーが渡していない情報をそれらしく補完しない

## 5. ワークフロー

1. 一度に全部書かず、章ごとに書く
2. 書き終えたら `python3 work/minsalo-chatgpt-test/tools/ai_smell.py <ファイル>` を実行
3. 判定B以上になるまで自分でリライトして再検査。結果はユーザーに見せる
4. 修正案を求められていないときは、指摘だけ出して直さない（人の手を残す）
