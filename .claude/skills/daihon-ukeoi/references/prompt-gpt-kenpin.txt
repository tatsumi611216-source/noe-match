# 前提：この台本が従うべき基準

この台本は、ある教育系YouTubeチャンネル群の実在動画を分析して作った
以下の基準に従っているはずです。あなたはこの基準を物差しにして検品してください。

【文体の基準（実測値）】
- 完全な話し言葉。一文は平均40字前後で、10〜80字の間で長短が揺れている
- 語尾は「〜すよね」「〜んです」が主軸。同じ語尾は3連続しない
- 視聴者の呼びかけは「皆さん」で統一されている
- 3文に1回程度、具体的な数字（分・件数・金額・回数）が入っている
- つなぎ言葉は「実は」「ちょっと」「逆に言うと」「で、」

【構成の基準】
- 冒頭はコールドオープン（挨拶より先に、得か損の話を3文以内で言い切る）
- 冒頭で「今日は◯つ」と本数を約束している
- 各項目は同じ順番：名前→一言定義→共感かリスク→画面実演→
  「たったこれだけで」の効果確認→注意点
- 項目の切り替えは毎回同じ言い回し（リフレイン）
- 変わりやすい固有名詞（モデル名・料金）は、名前ではなく役割で教えている
- 失敗談は全体で1〜2回だけ

【出てはいけないもの】
- 「いかがでしたか」「〜ではないでしょうか」「本記事では」「まとめると」
  「重要です」「近年」「様々な」「革新的」
- 均一な長さの文が続く区間、同じ語尾の連続、体言止めの連発
- 中身のない抽象的な励ましや、誰にでも言える一般論

# 検品してほしいこと（この順で）

1. 【AI臭】AIが書いたと感じる箇所を最大10個。
   必ず本文をそのまま引用し、なぜそう感じるかを1行で添える。
   文体の好みではなく、定型臭・不自然な均一さ・実感の無さに絞る
2. 【型ズレ】上の基準から外れている箇所をすべて。
   どの基準にどう反しているかを明記する
3. 【実感の穴】語り手の実体験が入るべきなのに一般論で流している箇所を3つ。
   「ここに書き手自身の体験を入れるべき」という場所の指摘だけでよい
4. 【事実の危うさ】数字・固有名詞・日付で、誤りの可能性を感じる箇所。
   正しい値を答える必要はない。「要検証」と指摘するだけでよい

# 出力形式

各指摘を「引用 → 問題 → 直し方の方向性（1行まで）」の形式で。
方向性は方針だけ。完成した文章は絶対に書かないでください。
