# 知見のスキル還流ルール

このリポジトリでの作業中に、次のいずれかが起きたら、その場でスキルに反映すること。
ユーザーからの依頼を待たない。

1. **同じ種類の作業を2回以上やった** → 手順をスキル化（または既存スキルに追記）
2. **失敗や誤判定から判断基準が生まれた** → 該当スキルの基準表に1行追加
3. **プロンプトを修正した** → 修正理由をスキルの「なぜ」として書き残す
4. **較正値・実測値が更新された** → スキル内の数値を差し替え、測定日を記す

反映先の目安：
- 台本・受注ライティング関連 → `.claude/skills/daihon-ukeoi/`（文体制御は `daihon/`）
- 汎用の知見 → daihon-ukeoi の「他ジャンルへの転用ガイド」節

反映したら、コミットメッセージに「何の失敗・発見から来たか」を1行書く。
スナップショットではなくループを育てるのがこの環境の価値なので、
反映漏れは資産の目減りとして扱う。
